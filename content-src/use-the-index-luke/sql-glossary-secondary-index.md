---
title: "Secondary Index"
lang: en
---

A secondary index is an index that refers to a [clustered index](/sql/glossary/clustered-index) (SQL Server, MySQL/InnoDB) or [Index-Organized Table](/sql/glossary/index-organized-table) (Oracle). In other words, an index on an index.

Accessing table data via a secondary index is slower than a similar query on a [heap-table](/sql/glossary/heap-table).
