## ماذا سنتعلّم؟

في الدرس السابق تعلّمنا المعاملات الديناميكية: نكتب `$postId` في اسم ملف المسار، فيلتقط الموجّه قيمةً من عنوان الصفحة. لكنّ ذلك المعامل كان إلزاميًّا، فلا يطابق المسارُ إلّا إذا حُضِر في الرابط.

في هذا الدرس نجعل بعض المعاملات اختيارية. خُذ مسارَ أرشيفٍ مثلًا: نريد لـ`/archive` وحدَه أن يعرض كلَّ ما في الأرشيف، وأن تقيّد `/archive/2024` الأرشيفَ بسنةٍ بعينها، و`/archive/2024/05` أرشيفَ شهرٍ، وأن يسبقه اختياريًّا رمزُ لغةٍ مثل `/fr/archive`. كلُّ هذه العناوين عنوانٌ واحدٌ في نظر المستخدم، ويخدمها ملفُ مسارٍ واحد.

## الشرح

### كيف نُعلن عن معاملٍ اختياري

المعاملُ الديناميكي يُكتب في اسم ملف المسار على هيئة `$name`. وجعلُه اختياريًّا يحتاج خطوتين: لفَّ الاسمَ بين أقواسٍ معقوفة، ووضعُ علامةِ ناقص قبل علامة الدولار. فتصير `{-$name}` بدل `$name`، فيعرف الموجّه أنّ غياب هذا المعامل جائزٌ لا خطأ.

ولأنّ الدرسَ السابق اعتمد تسميةَ الملفات بالطريقة المسطّحة، نجمع المعاملات الأربعة في ملفٍ واحد تفصل بين أجزائه نقاط:

- `src/routes/{-$locale}.archive.{-$year}.{-$month}.{-$day}.tsx`

> **توضيح من عندي:** الصيغةُ نفسها تصلح لو اخترتَ بدل النقاط مجلّداتٍ متداخلة تحمل الأسماءَ ذاتها، فكلُّ ما يُنجَز بالطريقة المسطّحة يمكن إنجازه بمجلّداتٍ أيضًا.

### المسارُ الذي ينشئه هذا الملف

هذه الشيفرةُ كاملةً كما هي في فرع الدرس:

```tsx
import { createFileRoute, Link } from "@tanstack/react-router";

const languages = [
  { code: "en", name: "English" },
  { code: "fr", name: "Français" },
  { code: "es", name: "Español" },
];

export const Route = createFileRoute(
  "/{-$locale}/archive/{-$year}/{-$month}/{-$day}"
)({
  component: RouteComponent,
});

function RouteComponent() {
  const { locale, year, day, month } = Route.useParams();
  return (
    <div>
      Hello "/-$locale/archive/-$year/-$month/-$day"!
      <div>
        <div className="flex gap-2 bg-amber-700 p-2 my-2">
          {languages.map(({ code, name }) => (
            <Link
              key={code}
              to="/{-$locale}/archive/{-$year}/{-$month}/{-$day}"
              params={(prev) => ({
                ...prev,
                locale: code === "en" ? undefined : code,
              })}
              className={
                locale === code || (!locale && code === "en") ? "font-bold" : ""
              }
            >
              {name}
            </Link>
          ))}
        </div>
      </div>
      <div>
        <p>Locale: {locale}</p>
        <p>Year: {year}</p>
        <p>Month: {month}</p>
        <p>Day: {day}</p>
      </div>
    </div>
  );
}
```

وفيها ثلاثُ نقاطٍ تستحقّ التوقّف:

1. **عنوانُ المسار** في `createFileRoute` يحمل الصيغةَ نفسها التي في اسم الملف: `/{-$locale}/archive/{-$year}/{-$month}/{-$day}`.
2. **`Route.useParams()`** تعيد المعاملات الأربعة، وكلُّها من نوع `string | undefined` لأنّها اختيارية.
3. **غيابُ اللغة** ليس خطأً: إن لم تُمرَّر `locale` فاللغةُ المختارة هي الافتراضية، ولهذا تُبرز الشيفرةُ `English` في حالة غيابها.

### المعاملُ الناقص يعني قيمةً غير موجودة

لأنّ المعاملات اختيارية، فإنّ حذفَ أيٍّ منها من عنوان الصفحة لا يُفقدنا الصفحة. جرّب في المتصفّح أن تفتح `archive/2024/05` ثم تحذفَ اليوم من العنوان: سيبقى المسارُ مطابقًا، وستأتي `day` بقيمة `undefined`. ولو حذفتَ السنة والشهر معًا لصار العنوان `archive` وحدَه، وتصبح `locale` و`year` و`month` و`day` كلُّها قيمًا غير موجودة.

ولهذا يجب التحقّقُ من وجود القيمة قبل أن تستعملها في أيّ عملٍ، كإرسالِ طلبٍ إلى الخادم مثلًا. منطقُ التطبيق هو الذي يقرّر معنى غياب المعامل: سنةٌ بلا شهرٍ قد تعني كلَّ أشهر السنة.

### الانتقالُ إلى المسار بمعاملات اختيارية

ولكي ننتقل إلى هذا المسار نستخدم مكوّن `Link` كما في الدرس السابق، ونمرّر المعاملاتَ في خاصية `params`. والصفحةُ الرئيسيةُ في فرع الدرس صارت كالتالي:

```tsx
import { createFileRoute, Link } from "@tanstack/react-router";

export const Route = createFileRoute("/")({
  component: RouteComponent,
});

function RouteComponent() {
  return (
    <div className="p-2 bg-violet-500">
      <h3 className="text-xl font-bold">Home</h3>
      <Link
        to="/{-$locale}/archive/{-$year}/{-$month}/{-$day}"
        params={{
          locale: "fr",
          year: "2009",
        }}
      >
        Go to Archive
      </Link>
    </div>
  );
}
```

لاحظ أنّنا لم نمرّر `month` ولا `day`، وهما معاملان اختياريان، فاكتفى الرابطُ بما مرّرناه. والنتيجةُ أن يبني العنوانُ من القطع التي مرّرناها فقط، فيصير `/fr/archive/2009`. أمّا لو مرّرتَ المعاملاتِ الأربعةَ جميعًا لبني العنوانُ كاملًا.

وقيمةُ كلِّ معاملٍ سلسلةٌ نصية: لو كتبتَ `year: 2009` بدل `year: "2009"` لأظهر المحرّرُ خطأً، لأنّ النوعَ المطلوب نصٌّ لا عدد.

### مبدّلُ اللغات: تغييرُ معاملٍ واحدٍ دون المساس بالباقي

الأمانةُ في مبدّل اللغات أنّ تغييرُ اللغة يجب ألّا يبدّل التاريخَ الذي يعرضه المستخدم. ولهذا نقبل في `params` دالّةً بدل كائن: تستقبل المعاملاتَ الحالية وتعيد الجديدة. وهذا الجزءُ من الملف أعلاه:

```tsx
          {languages.map(({ code, name }) => (
            <Link
              key={code}
              to="/{-$locale}/archive/{-$year}/{-$month}/{-$day}"
              params={(prev) => ({
                ...prev,
                locale: code === "en" ? undefined : code,
              })}
              className={
                locale === code || (!locale && code === "en") ? "font-bold" : ""
              }
            >
              {name}
            </Link>
          ))}
```

وفيه ثلاثُ نقاط:

1. **الدالّةُ تستقبل المعاملاتَ السابقة** في `prev`، والانتشارُ `...prev` يُبقي السنة والشهر واليوم كما هي.
2. **اللغةُ الافتراضية تُحذف من العنوان**: حين تكون اللغةُ المختارة `English` نمرّر `undefined` في `locale`، فيغيب المعاملُ من العنوان تمامًا لأنّه اختياري.
3. **إبرازُ اللغة الحالية** يعالج حالةَ الغياب أيضًا: الشرطُ `locale === code || (!locale && code === "en")` يجعل `English` غامقًا حين لا توجد `locale` في الرابط.

## النتيجة

في الصورة الصفحةُ على العنوان `archive/2024/05`: الشريطُ البرتقالي في الأعلى فيه `English` و`Français` و`Español`، و`English` وحده غامقٌ لأنّ `locale` غير موجودة في العنوان فهي اللغةُ الافتراضية. وتحته تُقرأ المعاملاتُ واحدًا واحدًا: `Locale` فارغ، و`Year` يساوي `2024`، و`Month` يساوي `05`، و`Day` فارغ. ولاحظ أنّ غياب `Day` لم يمنع مطابقةَ المسار، وأنّ الصفحةَ تظهر بالعنوان نفسه مهما كان عددُ المعاملات الغائبة.

## جرّب بنفسك

1. استنسخ مستودعَ الدورة وانتقل إلى فرع `optional-params`.
2. أنشئ الملف `src/routes/{-$locale}.archive.{-$year}.{-$month}.{-$day}.tsx` بالاستعانة بالشيفرة أعلاه.
3. شغّل `npm run dev` ثم افتح `archive` وحدَه، وتأكّد من ظهور الصفحة وأنّ كلَّ المعاملات فارغة.
4. افتح `archive/2024/05/17`، ثم احذف قطعًا من العنوان واحدًا واحدًا ولاحظ كيف يتحوّل كلُّ معاملٍ إلى `undefined` بينما يبقى المسارُ مطابقًا.
5. عد إلى الصفحة الرئيسية وأضف رابطًا آخر يمرّر `locale` وحدَه، ثم قارن العنوانَين الناتجين.
6. غيّر `year: "2009"` إلى `2009` ولاحظ خطأ المحرّر، ثم أعِده.
7. جرّب تغييرَ اللغة من الشريط البرتقالي ولاحظ أنّ السنة والشهر واليوم بقيت كما هي في العنوان، وأنّ اختيار `English` يزيل `locale` وحدَه.
