من الاستخدامات الشائعة جدًا في البرمجة التعامل مع البيانات المخزّنة في الملفات. فتستطيع البرامج قراءة البيانات من الملفات وكتابة النتائج المحسوبة في الملفات. وحتى كميات البيانات الكبيرة تصبح سهلة المعالجة تلقائيًّا عند استخدام الملفات.

في هذه الدورة نتعامل فقط مع _الملفات النصية_. فجميع الملفات المستخدَمة تتكوّن من أسطر نصية. ومثالًا على ذلك، محرّر Visual Studio Code الذي نستخدمه في هذه الدورة يعمل مع الملفات النصية. ملاحظة: رغم أن معالجات النصوص مثل Microsoft Word تُستخدم عادةً مع ملفات تحتوي على نص، فإن مستندات Word في ذاتها ليست ملفات نصية، إذ تحتوي أيضًا على معلومات التنسيق، وتُرمَّز بطريقة تجعل التعامل معها داخل برنامج أكثر تعقيدًا.

## قراءة البيانات من ملف

لنعمل أولًا مع ملف اسمه `example.txt`، ذي المحتوى التالي:


```
Hello there!
This example file contains three lines of text.
This is the last line.
```


طريقة بسيطة لتضمين الملفات في برنامج Python هي استخدام جملة `with`. فسطر الترويسة يفتح الملف، ثم تأتي الكتلة التي يمكن الوصول إلى الملف من خلالها. وبعد الكتلة يُغلق الملف تلقائيًّا، ولا يمكن الوصول إليه بعد ذلك.

إذًا، تفتح الشيفرة التالية الملف، وتقرأ محتوياته، وتطبعه، ثم تغلق الملف:

```python
with open("example.txt") as new_file:
    contents = new_file.read()
    print(contents)
```


```
Hello there!
This example file contains three lines of text.
This is the last line.
```


المتغيّر `new_file` أعلاه هو _مقبض الملف_ (file handle). ومن خلاله يمكن الوصول إلى الملف وهو ما زال مفتوحًا. هنا استخدمنا التابع `read`، الذي يعيد محتويات الملف كسلسلة نصية واحدة. إذًا، في هذه الحالة تكون السلسلة النصية التي تعيدها `read`:

```
"Hello there!\nThis example file contains three lines of text.\nThis is the last line."
```

## المرور على محتويات الملف

التابع `read` مفيد لطباعة محتويات الملف بأكمله، لكننا في الغالب نريد المرور على الملف سطرًا بسطر.

يمكن التفكير في الملفات النصية كقوائم من السلاسل النصية، تمثّل كل سلسلة نصية سطرًا واحدًا في الملف. ويمكننا المرور على القائمة بحلقة `for`.

المثال التالي يقرأ ملف المثال استخدامًا بحلقة `for`، ويزيل فواصل الأسطر من نهاية كل سطر، ويعدّ عدد الأسطر، ويطبع كل سطر مع رقم سطره. كما يتتبّع طول الأسطر:

```python
with open("example.txt") as new_file:
    count = 0
    total_length = 0

    for line in new_file:
        line = line.replace("\n", "")
        count += 1
        print("Line", count, line)
        length = len(line)
        total_length += length

print("Total length of lines:", total_length)
```


```
Line 1 Hello there!
Line 2 This example file contains three lines of text.
Line 3 This is the last line.
Total length of lines: 81
```


يوجد فاصل سطر `\n` في نهاية كل سطر في الملف، لكن الدالة `print` تضيف هي أيضًا فاصل سطر افتراضيًّا. ولا توجد فواصل أسطر زائدة في المخرجات أعلاه، لأن فواصل الأطراف في نهايات الأسطر تُزال بالتابع `replace`، الذي يستبدل كل محرف فاصل سطر بسلسلة نصية فارغة. وبهذه الطريقة تُحسب أطوال الأسطر أيضًا بشكل صحيح.

## قراءة ملفات CSV

ملف CSV، وهو اختصار لـ_قيم مفصولة بفواصل_ (_comma-separated Values_)، هو ملف نصي يحوي بيانات مفصولة بمحرف محدَّد مسبقًا. والمحارف الأكثر استخدامًا لهذا الغرض هي الفاصلة `,` والفاصلة المنقوطة `;`، لكن أي محرف ممكن على سبيل المبدأ.

تُستخدم ملفات CSV عادةً لتخزين سجلات من أنواع مختلفة. فكثير من برامج قواعد البيانات وجداول البيانات، مثل Excel، يمكنها استيراد البيانات وتصديرها بصيغة CSV، ما يجعل تبادل البيانات بين الأنظمة المختلفة سهلًا.

تعلّمنا بالفعل أنه يمكننا المرور على أسطر الملف بحلقة `for`، لكن كيف نفصل الحقول المختلفة في سطر واحد؟ تحتوي Python على تابع نصي `split` لهذا الغرض تحديدًا. يأخذ التابع محارف الفصل كوسيط نصي، ويعيد محتويات السلسلة النصية المستهدفة كقائمة من السلاسل النصية، مفصولة عند محارف الفصل.

مثال على عمل التابع:

```python
text = "monkey,banana,harpsichord"
words = text.split(",")
for word in words:
    print(word)
```


```
monkey
banana
harpsichord
```


لنفترض أن لدينا ملف `grades.csv` يحوي أسماء طلاب والدرجات التي حصلوا عليها في بعض المقررات. فكل سطر يحوي بيانات طالب واحد، والبيانات مفصولة بفاصلة منقوطة.


```
Paul;5;4;5;3;4;5;5;4;2;4
Beth;3;4;2;4;4;2;3;1;3;3
Ruth;4;5;5;4;5;5;4;5;4;4
```


البرنامج التالي يمرّ على الملف سطرًا بسطر، ويقسم كل سطر إلى أجزائه المنفصلة، ويطبع اسم كل طالب ودرجاته.

```python
with open("grades.csv") as new_file:
    for line in new_file:
        line = line.replace("\n", "")
        parts = line.split(";")
        name = parts[0]
        grades = parts[1:]
        print("Name:", name)
        print("Grades:", grades)
```


```
Name: Paul
Grades: ['5', '4', '5', '3', '4', '5', '5', '4', '2', '4']
Name: Beth
Grades: ['3', '4', '2', '4', '4', '2', '3', '1', '3', '3']
Name: Ruth
Grades: ['4', '5', '5', '4', '5', '5', '4', '5', '4', '4']
```


> **تمرين برمجي: سوق الفواكه**
>
> الملف `fruits.csv` يحوي أسماء فواكه وأسعارها، بالصيغة المحدَّدة في هذا المثال:

```sh
banana;6.50
apple;4.95
orange;8.0
...etc...
```

يُرجى كتابة دالة اسمها `read_fruits`، تقرأ الملف وتعيد قاموسًا مبنيًّا على محتوياته. وفي القاموس ينبغي أن يكون اسم الفاكهة هو المفتاح، وأن تكون القيمة هي سعرها. ويجب أن تكون الأسعار من النوع `float`.

ملاحظة: الدالة لا تأخذ أي وسيط. فالملف الذي تعمل عليه اسمه دائمًا `fruits.csv`.


> **تمرين برمجي: المصفوفة**
>
> الملف `matrix.txt` يحوي مصفوفة بالصيغة المحدَّدة في المثال أدناه:

```sh
1,0,2,8,2,1,3,2,5,2,2,2
9,2,4,5,2,4,2,4,1,10,4,2
...etc...
```

يُرجى كتابة دالتين، اسمهما `matrix_sum` و`matrix_max`. فكلاهما يمرّ على المصفوفة في الملف، ثم يعيد مجموع عناصرها أو العنصر ذا القيمة الأكبر، كما يوحي اسم الدالتين.

يُرجى أيضًا كتابة الدالة `row_sums`، التي تعيد قائمة تحتوي على مجموع كل صف في المصفوفة. فمثلًا، عند استدعاء `row_sums` عندما تكون المصفوفة في الملف معرَّفة هكذا

```sh
1,2,3
2,3,4
```

ينبغي أن تعيد الدالة القائمة `[6, 9]`.

تلميح: يمكنك أيضًا تضمين دوال مساعدة أخرى في برنامجك. ومن المفيد جدًا أن تخصّص لحظة للتفكير في الوظائف الثلاث التي تشترك فيها الدوال الثلاثة المطلوب منك كتابتها. لاحظ أن الدوال الثلاث المذكورة أعلاه لا تأخذ أي وسيط، لكن أي دوال مساعدة تكتبها قد تأخذ وسائط. والملف الذي تعمل عليه اسمه دائمًا `matrix.txt`.

**ملاحظة:** إذا لم تستطع Visual Studio Code العثور على الملف وقد تأكّدت من عدم وجود أخطاء إملائية، فاطّلع على التعليمات الواردة قبل هذا التمرين.


## قراءة نفس الملف عدة مرات

أحيانًا ما يكون من الضروري معالجة محتويات الملف أكثر من مرة في برنامج واحد. لننظر إلى برنامج يعمل مع بعض البيانات الشخصية المخزّنة في ملف CSV:


```
Peter;40;Helsinki
Emily;34;Espoo
Eric;42;London
Adam;100;Amsterdam
Alice;58;Paris
```


```python
with open("people.csv") as new_file:
    # print out the names
    for line in new_file:
        parts = line.split(";")
        print("Name:", parts[0])

    # find the oldest
    age_of_oldest = -1
    for line in new_file:
        parts = line.split(";")
        name = parts[0]
        age = int(parts[1])
        if age > age_of_oldest:
            age_of_oldest = age
            oldest = name
    print("the oldest is", oldest)
```

سيؤدي تشغيل هذا إلى رسالة خطأ غامضة بعض الشيء:

```python
Traceback (most recent call last):
    print("the oldest is"; oldest)
UnboundLocalError: local variable 'oldest' referenced before assignment
```

السبب في حدوث ذلك أن حلقة `for` الثانية لا تُنفَّذ إطلاقًا، لأن الملف لا يمكن معالجته إلا مرة واحدة. فبمجرد قراءة السطر الأخير يستقرّ مقبض الملف في نهاية الملف، ولا يمكن الوصول إلى البيانات الموجودة فيه بعد ذلك.

إذا أردنا الوصول إلى المحتويات في حلقة `for` الثانية، فسيتعيّن علينا فتح الملف مرة ثانية باستخدام `open`:

```python
with open("people.csv") as new_file:
    # print out the names
    for line in new_file:
        parts = line.split(";")
        print("Name:", parts[0])

with open("people.csv") as new_file:
    # find the oldest
    age_of_oldest = -1
    for line in new_file:
        parts = line.split(";")
        name = parts[0]
        age = int(parts[1])
        if age > age_of_oldest:
            age_of_oldest = age
            oldest = name
    print("the oldest is", oldest)
```

مع أن الشيفرة أعلاه ستعمل، فإنها تتضمن تكرارًا غير ضروري. فمن الأفضل عادةً قراءة الملف مرة واحدة فقط، وتخزين محتوياته في صيغة مناسبة للمعالجة اللاحقة:

```python
people = []
# read the contents of the file and store it in a list
with open("people.csv") as new_file:
    for line in new_file:
        parts = line.split(";")
        people.append((parts[0], int(parts[1]), parts[2]))

# print out the names
for person in people:
    print("Name:", person[0])

# find the oldest
age_of_oldest = -1
for person in people:
    name = person[0]
    age = person[1]
    if age > age_of_oldest:
        age_of_oldest = age
        oldest = name
print("the oldest is", oldest)
```

## المزيد من معالجة ملفات CSV

لنواصل مع الملف `grades.csv`، ذي المحتوى التالي:


```
Paul;5;4;5;3;4;5;5;4;2;4
Beth;3;4;2;4;4;2;3;1;3;3
Ruth;4;5;5;4;5;5;4;5;4;4
```


ينشئ البرنامج التالي قاموسًا اسمه `grades` مبنيًّا على محتوى الملف. فالمفاتيح هي أسماء الطلاب، والقيمة المرتبطة بكل مفتاح هي قائمة الدرجات التي حصل عليها الطالب. ويحوّل البرنامج الدرجات إلى قيم صحيحة لتسهيل معالجتها.

```python
grades = {}
with open("grades.csv") as new_file:
    for line in new_file:
        line = line.replace("\n", "")
        parts = line.split(";")
        name = parts[0]
        grades[name] = []
        for grade in parts[1:]:
            grades[name].append(int(grade))

print(grades)
```


```
{'Paul': [5, 4, 5, 3, 4, 5, 5, 4, 2, 4], 'Beth': [3, 4, 2, 4, 4, 2, 3, 1, 3, 3], 'Ruth': [4, 5, 5, 4, 5, 5, 4, 5, 4, 4]}
```


الآن يمكننا طباعة بعض الإحصاءات عن كل طالب بناءً على محتويات القاموس `grades`:

```python
for name, grade_list in grades.items():
    best = max(grade_list)
    average = sum(grade_list) / len(grade_list)
    print(f"{name}: best grade {best}, average {average:.2f}")
```


```
Paul: best grade 5, average 4.10
Beth: best grade 4, average 2.90
Ruth: best grade 5, average 4.50
```


يُرجى الاطلاع الدقيق على البرنامج في المثال أعلاه. فقد يبدو معقّدًا بعض الشيء في البداية، لكن يمكن استخدام هذه الطريقة مع ملفات تحوي أنواعًا مختلفة كثيرة من البيانات.

## إزالة الأسطر والمسافات وفواصل الأسطر غير الضرورية

لنفترض أن لدينا ملف CSV يحوي بعض الأسماء، قد صُدِّر من Excel:

```sh
first; last
Paul; Python
Jean; Java
Harry; Haskell
```

اشتهر Excel بإضافة مسافات بيضاء زائدة. فهنا يوجد محرف مسافة زائد بين العناصر، بعد كل فاصلة منقوطة.

نودّ طباعة أسماء العائلة لكل شخص في القائمة. يحتوي السطر الأول على ترويسات البيانات، ويمكن تجاهله بأمان:

```python
last_names = []
with open("people.csv") as new_file:
    for line in new_file:
        parts = line.split(";")
        # ignore the header line
        if parts[0] == "first":
            continue
        last_names.append(parts[1])

print(last_names)
```

سيؤدي تنفيذ هذا إلى طباعة


```
[' Python\n', ' Java\n', ' Haskell']
```


العنصران الأولان يحملان محرف فاصل سطر في نهايتهما، والثلاثة جميعًا تحوي محرف مسافة زائدًا في بدايتها.

لقد استخدمنا بالفعل التابع `replace` لإزالة المسافات البيضاء الزائدة، لكن الحل الأكثر كفاءة هو استخدام التابع النصي `strip` في Python، الذي يزيل المسافات البيضاء من بداية السلسلة النصية ونهايتها. فهو يزيل جميع المسافات وفواصل الأسطر وأحرف الجدولة وغيرها من المحارف التي لا تُطبع عادةً.

يمكنك تجربته في مفسّر Python:

```python
>>> " tryout ".strip()
'tryout'
>>> "\n\ntest\n".strip()
'test'
>>>
```

إنزال المسافة البيضاء عن السلسلة النصية يتطلب تغييرًا بسيطًا فقط في البرنامج:

```python
last_names = []
with open("people.csv") as new_file:
    for line in new_file:
        parts = line.split(';')
        if parts[0] == "first":
            continue # this was the header line, so it is ignored
        last_names.append(parts[1].strip())
print(last_names)
```

الآن حصلنا على المخرج المرغوب المرتب:


```
['Python', 'Java', 'Haskell']
```


هناك أيضًا التابعان المتماثلان `lstrip` و`rstrip`. فيزيلان المحارف غير القابلة للطباعة من البداية أو النهاية فقط، حيث تعني الحرف l الحافة اليسرى للسلسلة النصية ويعني الحرف r الحافة اليمنى:

```python
>>> " teststring  ".rstrip()
' teststring'
>>> " teststring  ".lstrip()
'teststring  '
```

```python
names = {}

with open("employees.csv") as new_file:
    for line in new_file:
        parts = line.split(';')
        if parts[0] == "pic":
            continue
        names[parts[0]] = parts[1]

        parts = line.split(';')
        if parts[0] == "pic":
            continue
        salaries[parts[0]] = int(parts[1]) +int(parts[2])

print("incomes:")

for pic, name in names.items():
    if pic in salaries:
        salary = salaries[pic]
        print(f"{name:16} {salary} euros")
    else:
        print(f"{name:16} 0 euros")
```

#### المسافة بين المحطات

أولًا، اكتب دالة اسمها `get_station_data(filename: str)`. ينبغي لهذه الدالة أن تقرأ أسماء جميع المحطات ومواقعها في الملف، وتعيدها في قاموس ذو الصيغة التالية:

```
  "Kapteeninpuistikko": (24.944927399779715, 60.158189199971673)

```


مفاتيح القاموس هي أسماء المحطات، والقيمة المرتبطة بها صف (tuple) يحوي إحداثيات موقع المحطة. فالعنصر الأول في الصف هو حقل _خط الطول_ (Longitude)، والعنصر الثاني هو حقل _خط العرض_ (Latitude).

ثم اكتب دالة اسمها `distance(stations: dict, station1: str, station2: str)`، تعيد المسافة بين المحطتين المحدَّدتين في وسيطيها.

تُحسب المسافة باستخدام نظرية فيثاغورس. ومعاملات الضرب أدناه قيم تقريبية لتحويل خطوط الطول وخطوط العرض إلى مسافات بالكيلومترات في منطقة هلسنكي.

```python
# we will need the function sqrt from the math module
```
