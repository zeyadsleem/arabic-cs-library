PAGE 3 TITLE: Go offline (optional)

  <h2>Go offline (optional)</h2>


  <p>
    This tour is also available as a stand-alone program that you can use


    without access to the internet. It builds and runs the code samples on


    your own machine.
  </p>



  <p>
    To run the tour locally, you&#39;ll need to first


    <a href="/doc/install" target="_self">install Go</a> and then run:
  </p>



  <pre>go install golang.org/x/website/tour@latest</pre>



  <p>
    This will place a <code>tour</code> binary in your


    <a href="/cmd/go/#hdr-GOPATH_and_Modules" target="_self">GOPATH</a>&#39;s <code>bin</code> directory.


    When you run the tour program, it will open a web browser displaying


    your local version of the tour.
  </p>



  <p>
    Of course, you can continue to take the tour through this web site.
  </p>



END PAGE 3

PAGE 4 TITLE: The Go Playground

  <h2>The Go Playground</h2>


  <p>
    This tour is built atop the <a href="https://play.golang.org/" target="_blank">Go Playground</a>, a


    web service that runs on <a href="/" target="_self">golang.org</a>&#39;s servers.
  </p>



  <p>
    The service receives a Go program, compiles, links, and runs the program inside


    a sandbox, then returns the output.
  </p>



  <p>
    There are limitations to the programs that can be run in the playground:
  </p>


  <ul>

    <li>In the playground the time begins at 2009-11-10 23:00:00 UTC (determining the significance of this date is an exercise for the reader). This makes it easier to cache programs by giving them deterministic output.</li>

  </ul>

  <ul>

    <li>There are also limits on execution time and on CPU and memory usage, and the program cannot access external network hosts.</li>

  </ul>


  <p>
    The playground uses the latest stable release of Go.
  </p>



  <p>
    Read &#34;<a href="/blog/playground" target="_self">Inside the Go Playground</a>&#34; to learn more.
  </p>
