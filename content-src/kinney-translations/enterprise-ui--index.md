تُعلِّم هذه الدورة مهندسي الواجهة الأمامية كبارًا كيفية توسيع التطبيقات ما بعد تطبيق SPA يديره فريق واحد — تغطي أنماط التكين (composition) (الواجهات المصغّرة microfrontends، والمستودعات الأحادية monorepos، ومكوّنات الخادم server components)، والبنية التحتية التشغيلية (توسيع TypeScript، والفحص المعماري architectural linting، وCI/CD، والاختبارات)، واستراتيجيات الترحيل (strangler fig، وcodemods). يبني الطلاب ويُطوّرون قاعدة شيفرة حقيقية عبر تسع تمارين عملية، ليختبروا المقايضات (trade-offs) بأنفسهم، حتى يتمكنوا من اتخاذ قرارات معمارية مدروسة لتنظيماتهم الخاصة.
