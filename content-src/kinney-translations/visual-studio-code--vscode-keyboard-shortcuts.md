## التنقّل والبحث العام

| الإجراء | اختصار macOS | اختصار Windows | الوصف |
| --- | --- | --- | --- |
| **لوحة الأوامر** | **Cmd + Shift + P** | **Ctrl + Shift + P** | الوصول إلى جميع الأوامر والإعدادات وغيرها. |
| **الانتقال إلى ملف** | **Cmd + P** | **Ctrl + P** | البحث التقريبي عن الملفات وفتحها. |
| **البحث في الملفات** | **Cmd + Shift + F** | **Ctrl + Shift + F** | بحث شامل في جميع الملفات والمجلدات. |
| **إظهار/إخفاء الطرفية** | **Ctrl + `** | **Ctrl + `** | إظهار الطرفية المدمجة أو إخفاؤها. (العلامة الخلفية ` هي المفتاح فوق Tab.) |
| **إظهار/إخفاء الشريط الجانبي** | **Cmd + B** | **Ctrl + B** | إظهار الشريط الجانبي الأيسر (مستكشف الملفات وغيره) أو إخفاؤه. |
| **الرجوع للخلف** | **Ctrl + -** | **Alt + Left Arrow** | العودة إلى الموضع السابق في الشيفرة. |
| **التقدّم للأمام** | **Ctrl + Shift + -** | **Alt + Right Arrow** | الانتقال إلى الموضع التالي في الشيفرة. |

## أساسيات التحرير

| الإجراء | اختصار macOS | اختصار Windows | الوصف |
| --- | --- | --- | --- |
| **قصّ السطر** (بلا حاجة إلى تحديد) | **Cmd + X** | **Ctrl + X** | يقصّ السطر كاملًا إذا لم يكن هناك أي تحديد. |
| **نسخ السطر** (بلا حاجة إلى تحديد) | **Cmd + C** | **Ctrl + C** | ينسخ السطر كاملًا إذا لم يكن هناك أي تحديد. |
| **اللصق** | **Cmd + V** | **Ctrl + V** | يلصق آخر ما قصصته أو نسخته. |
| **مضاعفة السطر** | **Shift + Option + ↓** | **Shift + Alt + ↓** | ينسخ سطرك الحالي مباشرة أسفله. |
| **تحريك السطر لأعلى/لأسفل** | **Option + ↑/↓** | **Alt + ↑/↓** | يحرّك السطر الحالي (أو التحديد) لأعلى أو لأسفل. |
| **تحديد المطابقة التالية** | **Cmd + D** | **Ctrl + D** | يجد المطابقة التالية تمامًا لتحديدك الحالي ويضيف مؤشّرًا جديدًا. |
| **تحديد جميع المطابقات** | **Cmd + Shift + L** | **Ctrl + Shift + L** | يبرز كل الكلمات المطابقة في الملف دفعة واحدة (مؤشّرات متعدّدة). |
| **تعليق/إلغاء تعليق السطر** | **Cmd + /** | **Ctrl + /** | يبدّل تعليق السطر (//) أو يحوّل تحديدًا إلى تعليق. |
| **تبديل تعليق الكتلة** | **Shift + Option + A** | **Shift + Alt + A** | يلفّ النص المحدّد في تعليق كتلة أو يزيل اللفّ. |
| **إضافة مؤشّرات متعدّدة** | **Option + Cmd + Up/Down** *أو* **Option + Click** | **Ctrl + Alt + Up/Down** *أو* **Alt + Click** | يضيف مؤشّرات متعدّدة للتحرير على التوازي. |
| **حذف السطر** | *غير مرتبط افتراضيًا (يُقترح Ctrl+Shift+K)* | **Ctrl + Shift + K** (افتراضيًا) | يحذف السطر الحالي كاملًا. |
| **دمج الأسطر** | (اربطه يدويًا، مثل **Ctrl+J**) | (اربطه يدويًا، مثل **Ctrl+J**) | يدمج السطر التالي في نهاية السطر الحالي (بلا فاصل سطر). |

## الذكاء البرمجي

| الإجراء | اختصار macOS | اختصار Windows | الوصف |
| --- | --- | --- | --- |
| **الانتقال إلى التعريف** | **F12** أو **Cmd + Click** | **F12** أو **Ctrl + Click** | ينتقل إلى موضع تعريف الرمز (دالة أو متغيّر). |
| **معاينة التعريف** | **Option + F12** | **Alt + F12** | يعرض التعريف في نافذة منبثقة دون مغادرة ملفك. |
| **إعادة تسمية الرمز** | **F2** | **F2** | يعيد تسمية جميع حالات الرمز (دالة، متغيّر، وغيرها). |
| **اقتراحات الإكمال التلقائي** | **Ctrl + Space** | **Ctrl + Space** | يُظهر اقتراحات intellisense لإكمالات مبنية على السياق. |

## التخطيط والتنسيق

| الإجراء | اختصار macOS | اختصار Windows | الوصف |
| --- | --- | --- | --- |
| **تنسيق المستند** | **Shift + Option + F** | **Shift + Alt + F** | ينسّق شيفرتك (بواسطة Prettier أو مُجمّل الكود وغيره). |
| **تبديل التفاف الكلمات** | **Option + Z** | **Alt + Z** | يلفّ أسطر الشيفرة الطويلة إلى السطر التالي. |
| **طيّ الكل / فتح الكل** | **Cmd + K + 0 / Cmd + K + J** | **Ctrl + K + 0 / Ctrl + K + J** | يطوي جميع المناطق القابلة للطيّ في الملف أو يفردها. |
| **تقسيم المحرّر** | **Cmd + ** | **Ctrl + ** | يقسّم نافذة المحرّر النشطة إلى عدّة أجزاء. |
| **التركيز على مجموعة المحرّرات التالية/السابقة** | **Ctrl + Cmd + → / ←** | **Ctrl + K Ctrl + → / ←** | ينقل التركيز بين الأجزاء المقسّمة (أو استخدم مفاتيح الأسهم). |
| **تبديل وضع ملء الشاشة** | **Ctrl + Cmd + F** | **F11** | يبدّل عرض ملء الشاشة. |
| **وضع Zen** | **Cmd + K Z** | **Ctrl + K Z** | وضع خالٍ من المشتّتات. |
