# Fundamentals of Frontend Architecture — النسخة العربية

المؤلف: Maxi Ferreira (Frontend at Scale).
المصدر: https://frontendatscale.com/courses/frontend-architecture/
تاريخ لقطة المصدر: 2026-10-05.

أكّد زياد سليم، مالك المكتبة، بتاريخ 2026-10-05 أن المؤلف وافق على ترجمة الكورس وإضافته إلى المكتبة. هذا إذن لهذا الاستخدام؛ لا ننسب إلى الأصل رخصة مفتوحة غير معلنة. حقوق المحتوى الأصلي للمؤلف، وهذه ترجمة عربية غير رسمية.

يشمل النطاق جميع صفحات الدروس الـ38، والتفريغات بالطوابع الزمنية، والتعليمات والتمارين، وعناوين الموارد وروابطها، والمخططات المعروضة داخل الدروس. الفيديوهات والموارد الخارجية تظل في مواقع أصحابها؛ لا تُرفع نسخ من الفيديو أو من المستودعات والكتب الخارجية.

- `source.json`: المحتوى المنشور للدروس وبيانات الفيديو، من دون نموذج الاشتراك أو الشيفرة الخاصة بالموقع الأصلي.
- `translations.json`: ترجمة جميع العقد النصية، مفهرسة ببصمة SHA-256 للنص الأصلي.
- `scripts/import-frontend-architecture.mjs`: يعيد توليد ملفات الدروس والفهرس محلياً، ويتوقف عند غياب ترجمة.
- `tests/frontend-architecture.test.mjs`: يفحص اكتمال الدروس والفقرات والطوابع الزمنية والروابط والشيفرة والفيديوهات.

الترجمة الأولية أُعدّت بمساعدة نموذج OPUS-MT-tc-big-en-ar (Helsinki-NLP، CC BY 4.0)، ثم روجعت مصطلحاتها وأُصلحت مواضع الالتباس. النص المصدر محفوظ للمقارنة. يمكن مراجعة أو تعديل ترجمة بعينها ثم تشغيل:

```sh
node scripts/import-frontend-architecture.mjs
pnpm content
node --test tests/frontend-architecture.test.mjs
```
