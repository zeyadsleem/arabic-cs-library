[Vue](https://vuejs.org/) is a popular progressive JavaScript framework used for building user interfaces. Unlike other monolithic frameworks, Vue is designed to be incrementally adoptable. This means it’s as easy to start with as jQuery, but it also has the potential to power sophisticated applications when used in combination with modern tooling and supporting libraries.

Understanding and leveraging Vue patterns can greatly help in writing clean, efficient, and maintainable code. In this site, we’ll go go through popular Vue specific patterns and behaviours which cover concepts like:

- [Composables](/vue/composables)
- [Script Setup](/vue/script-setup)
- [State Management](/vue/state-management)
- [Provide/Inject](/vue/provide-inject)
- [Dynamic Components](/vue/dynamic-components)
- and more…

Whether you’re new to Vue or looking to better understand some useful patterns, we’ve hopefully got you covered! With that said, let’s dive into the Vue-tiful world of Vue patterns.
