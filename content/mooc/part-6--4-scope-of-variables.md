_نطاق_ (scope) المتغير يشير إلى أقسام البرنامج حيث يمكن الوصول للمتغير. المتغير _المحلي_ (local) لا يمكن الوصول إليه إلا في قسم محدد من البرنامج، بينما المتغير _العالمي_ (global) متاح للاستخدام في أي قسم من البرنامج.

## المتغيرات المحلية

المتغيرات المعرفة داخل دالة Python هي متغيرات محلية، متاحة فقط داخل الدالة. هذا ينطبق على كل من معاملات الدالة، والمتغيرات الأخرى المعرفة داخل تعريف الدالة. المتغير المحلي لدالة _غير موجود خارج الدالة_.

في المثال التالي نحاول الوصول للمتغير `x` في الدالة الرئيسية، لكن هذا يسبب خطأ:

```python
def testing():
    x = 5
    print(x)

testing()
print(x)
```


```
5
NameError: name 'x' is not defined
```


المتغير `x` موجود فقط أثناء تنفيذ الدالة `testing`. الدوال الأخرى أو الدالة الرئيسية لا يمكنها الوصول للمتغير.

## المتغيرات العالمية

المتغيرات المعرفة داخل الدالة الرئيسية هي متغيرات عالمية. عرّفنا سابقاً الدالة الرئيسية بأنها تلك الأقسام من الكود في برنامج Python التي لا تقع داخل أي دالة أخرى. القيمة المخزنة في متغير عالمي يمكن الوصول إليها من أي دالة أخرى في البرنامج، لذا ما يلي لا يسبب أي أخطاء:

```python
def testing():
    print(x)

x = 3
testing()
```


```
3
```

    x = 5
