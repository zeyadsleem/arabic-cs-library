الزمرة (tuple) هي بنية بيانات تشبه القائمة في نواحٍ كثيرة. أهم الفروقات بين الاثنين هي:

* الزمر تُحاط بأقواس `()`، بينما القوائم تُحاط بأقواس مربعة `[]`
* الزمر _غير قابلة للتغيير_ (immutable)، بينما محتويات القائمة قد تتغير

الكود التالي ينشئ زمرة تحتوي على إحداثيات نقطة:

```python
point = (10, 20)
```

العناصر المخزنة في الزمرة تُصل بالفهرس، تماماً مثل العناصر المخزنة في القائمة:

```python
point = (10, 20)
print("x coordinate:", point[0])
print("y coordinate:", point[1])
```


```
x coordinate: 10
y coordinate: 20
```


القيم المخزنة في الزمرة لا يمكن تغييرها بعد تعريف الزمرة. ما يلي _لن يعمل_:

```python
point = (10, 20)
point[0] = 15
```


```
TypeError: 'tuple' object does not support item assignment
```

>
> اكتب دالة باسم `create_tuple(x: int, y: int, z: int)`، تأخذ ثلاثة أعداد صحيحة كمعاملات، وتنشئ وتعيد زمرة بناءً على المعايير التالية:

1. العنصر الأول في الزمرة هو الأصغر من المعاملات
2. العنصر الثاني في الزمرة هو الأكبر من المعاملات
3. العنصر الثالث في الزمرة هو مجموع المعاملات

مثال على استخدامها:

```python

if __name__ == "__main__":
    print(create_tuple(5, 3, -1))

```


```
(-1, 5, 7)
```
