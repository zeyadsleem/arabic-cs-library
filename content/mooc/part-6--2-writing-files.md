حتى الآن قرأنا البيانات من الملفات، لكن من الطبيعي أنه يمكن أيضاً كتابة البيانات إلى الملفات. عادة البرنامج يعالج البيانات ويخزن النتائج في ملف، لكي يمكن استخدامها لاحقاً أو معالجتها بشكل أكبر بواسطة برنامج آخر.

يمكننا إنشاء ملف جديد في كل مرة نريد كتابة بيانات في ملف، لكن يمكننا أيضاً إضافة بيانات جديدة إلى نهاية ملف موجود. في الحالتين نستخدم الدالة `open` من القسم السابق. لكتابة الملفات، الدالة تتطلب وسيطاً (argument) ثانياً.

## إنشاء ملف جديد

إذا أردت إنشاء ملف جديد، ستستدعي الدالة `open` مع الوسيط الإضافي `w`، للإشارة إلى أنه يجب فتح الملف في وضع الكتابة (write mode). لذا استدعاء الدالة قد يبدو هكذا:

```python
with open("new_file.txt", "w") as my_file:
    # code to write something to the file
```

**ملاحظة: إذا كان الملف موجوداً بالفعل، سيتم الكتابة فوق كل المحتويات**. من المجدي جداً توخي الحذر عند إنشاء ملفات جديدة.

مع فتح الملف، يمكنك كتابة البيانات فيه. يمكنك استخدام الدالة `write`، التي تأخذ النص المراد كتابته كوسيط.

```python
with open("new_file.txt", "w") as my_file:
    my_file.write("Hello there!")
```

عند تنفيذ البرنامج، يظهر ملف جديد باسم `new_file.txt` في الدليل. المحتويات ستبدو هكذا:


```
Hello there!
```
