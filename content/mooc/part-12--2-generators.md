لقد واجهنا بالفعل مواقف نتعامل فيها مع سلسلة من العناصر، ونحتاج إلى العنصر (العناصر) التالي في السلسلة، ولكننا لا نريد بالضرورة صياغة السلسلة بأكملها حتى تلك النقطة في كل مرة يُطلب فيها عنصر جديد. بعض السلاسل التكرارية، مثل أرقام فيبوناتشي (Fibonacci)، هي مثال جيد على مثل هذا الموقف. إذا كان كل استدعاء دالة يولد السلسلة بأكملها بشكل تكراري حتى النقطة المطلوبة، فسننتهي بتوليد بداية السلسلة عدة مرات.

مولّدات (generators) Python هي طريقة لإنتاج العنصر التالي في السلسلة فقط عند الحاجة إليه، مما يؤدي أساسًا إلى تشغيل عملية توليد السلسلة مرة واحدة فقط (لتنفيذ معين للبرنامج). إنها تعمل في الغالب مثل الدوال العادية، حيث يمكن استدعاؤها وستعيد قيمًا، ولكن القيمة التي تعيدها دالة المولّد تختلف عن الدالة العادية. يجب أن تعيد الدالة العادية نفس القيمة في كل مرة، معطاة نفس الوسائط. من ناحية أخرى، يجب أن تتذكر دالة المولّد حالتها الحالية وتعيد العنصر التالي في السلسلة، والذي قد يكون مختلفًا عن العنصر السابق.

 تمامًا كما توجد طرق عديدة لحل أي مشكلة برمجية تقريبًا، توجد طرق عديدة لتحقيق وظيفة مشابهة للمولّدات، لكن المولّدات يمكن أن تساعد في جعل البرنامج أسهل في الفهم، ويمكن أن توفر في مواقف معينة الذاكرة أو موارد حسابية أخرى.

## الكلمة المفتاحية yield

يجب أن تحتوي دالة المولّد على الكلمة المفتاحية `yield`، التي تحدد القيمة التي تعيدها الدالة. لنلقِ نظرة على دالة تولد أرقامًا صحيحة، تبدأ من الصفر وتنتهي عند قيمة قصوى محددة مسبقًا:

```python

def counter(max_value: int):
    number = 0
    while number <= max_value:
        yield number
        number += 1

```

الآن يمكن تمرير دالة `counter` كوسيط إلى الدالة `next()`:

```python
if __name__ == "__main__":
    numbers = counter(10)
    print("First value:")
    print(next(numbers))
    print("Second value:")
    print(next(numbers))
```


```
First value:
0
Second value:
1
```


كما ترى من المثال أعلاه، الكلمة المفتاحية `yield` مشابهة للكلمة المفتاحية `return`: كلاهما يُستخدمان لتعريف قيمة الإرجاع. الفرق هو أن `yield` لا "تغلق" الدالة بنفس معنى `return`. دالة المولّد التي تحتوي على الكلمة المفتاحية `yield` تحتفظ بتتبع حالتها، وفي المرة التالية التي يتم فيها استدعاؤها، ستستمر من نفس الحالة.

يتطلب هذا المولّد أيضًا قيمة قصوى، والتي كانت `10` في المثال أعلاه. عندما ينفد المولّد من القيم، سيرفع استثناء `StopIteration`:

```python
if __name__ == "__main__":
    # creates a generator with maximum value 1
    numbers = counter(1)
    print(next(numbers))
    print(next(numbers))
    print(next(numbers))
```


```
0
1
Traceback (most recent call last):
  File "generator_example.py", line 11, in <module>
    print(next(numbers))
StopIteration
```


يمكن التقاط الاستثناء باستخدام كتلة `try` - `except`:

```python
if __name__ == "__main__":
    numbers = counter(1)
    try:
        print(next(numbers))
        print(next(numbers))
        print(next(numbers))
    except StopIteration:
        print("ran out of numbers")
```


```
0
1
ran out of numbers
```


التنقل عبر جميع العناصر في المولّد يتم بسهولة باستخدام حلقة `for`:

```python
if __name__ == "__main__":
    numbers = counter(5)
    for number in numbers:
        print(number)
```


```
0
1
2
3
4
5
```


لا يجب أن يكون للمولّدات قيمة قصوى أو نقطة انتهاء محددة. يمكنها توليد القيم إلى ما لا نهاية (ضمن قيود حسابية وفيزيائية أخرى، بطبيعة الحال). 

انتبه، مع ذلك: التنقل عبر المولّد باستخدام حلقة `for` يعمل فقط إذا كان المولّد ينتهي عند نقطة ما. إذا كان المولّد مبنيًا على حلقة لا نهائية، فإن محاولة التنقل فيه باستخدام حلقة `for` بسيطة ستسبب تنفيذًا لا نهائيًا، تمامًا مثل حلقة `while` بدون شرط نهاية أو كسر (break).

## استبطان المولّدات (Generator comprehensions)

أنت لا تحتاج بالضرورة إلى تعريف دالة لإنشاء مولّد. يمكننا استخدام هيكل مشابه لاستبطان القائمة (list comprehension). هذه المرة نستخدم أقواسًا _دائرية_ للإشارة إلى مولّد بدلاً من قائمة أو قاموس:

```python
# This generator returns squares of integers
squares = (x ** 2 for x in range(1, 64))

print(squares) # the printout of a generator object isn't too informative

for i in range(5):
    print(next(squares))
```


```
<generator object <genexpr> at 0x000002B4224EBFC0>
1
4
9
16
25
```


في المثال التالي نطبع أجزاءً فرعية (substrings) من الأبجدية الإنجليزية، كل منها ثلاثة أحرف طويلة. هذا يطبع أول 10 عناصر في المولّد:

```python
substrings = ("abcdefghijklmnopqrstuvwxyz"[i : i + 3] for i in range(24))

# print out first 10 substrings
for i in range(10):
    print(next(substrings))
```


```
abc
bcd
cde
def
efg
fgh
ghi
hij
ijk
jkl
```


> **تمرين برمجي: تمرين برمجي**
>
> يرجى كتابة دالة باسم `word_generator(characters: str, length: int, amount: int)` تعيد مولّدًا جديدًا لتوليد كلمات عشوائية بناءً على الوسائط المعطاة.

يتم توليد كلمة عشوائية عن طريق الاختيار من السلسلة المسماة `characters` بعدد من الأحرف كما يشير الوسيط `length`. يمكن أن يظهر نفس الحرف عدة مرات في كلمة عشوائية.

يعيد المولّد عددًا من الكلمات كما هو محدد بالوسيط `amount` قبل إنهاء العمل.

مثال على تشغيل مولّد الكلمات:

```python
wordgen = word_generator("abcdefg", 3, 5)
for word in wordgen:
    print(word)
```

