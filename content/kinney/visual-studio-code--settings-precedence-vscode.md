---
title: "أسبقية الإعدادات في Visual Studio Code"
lang: ar

---

تُنظَّم إعدادات Visual Studio Code في نظام هرمي يتيح لك تعريف التكوينات على نطاقات مختلفة. وتضمن هذه الهرمية المرونة، فتمكّنك من تطبيق إعدادات عامة على جميع مشاريعك مع مراعاة الاحتياجات الخاصة بكل مشروع. ومستويات الإعدادات، مرتّبة حسب الأسبقية (من الأقل تحديدًا إلى الأكثر تحديدًا)، هي:

- **الإعدادات الافتراضية:** هي الإعدادات المدمجة التي يأتي بها Visual Studio Code. وهي التكوين الأساسي، وللقراءة فقط. ويمكنك عرضها في محرّر الإعدادات بالنقر على زر “Open Default Settings (JSON)” في شريط أدوات محرّر الإعدادات، أو بفتح لوحة الأوامر (`Ctrl+Shift+P` أو `Cmd+Shift+P`) وتشغيل “Preferences: Open Default Settings (JSON)“. وفهم الإعدادات الافتراضية مفيد لمعرفة ما يمكن ضبطه.
- **إعدادات المستخدم:** تُطبَّق هذه الإعدادات عامةً على جميع نُسخ Visual Studio Code التي تفتحها، بصرف النظر عن المشروع أو مساحة العمل. وإعدادات المستخدم مثالية للتفضيلات الشخصية التي تريد الحفاظ عليها في جميع أنشطة تطويرك. وتُخزَّن إعدادات المستخدم في: **Windows:** `%APPDATA%\Code\User\settings.json` و**macOS:** `~/Library/Application Support/Code/User/settings.json` و**Linux:** `~/.config/Code/User/settings.json`
  - **Windows:** `%APPDATA%\Code\User\settings.json`
  - **macOS:** `~/Library/Application Support/Code/User/settings.json`
  - **Linux:** `~/.config/Code/User/settings.json`
- **إعدادات مساحة العمل:** إعدادات مساحة العمل خاصة بمساحة العمل أو المجلد المفتوح حاليًا. ومساحة العمل في Visual Studio Code هي عادةً الدليل الجذر لمشروعك. وتتجاوز هذه الإعدادات إعدادات المستخدم، وهي مثالية للتكوينات الخاصة بالمشروع، مثل قواعد تنسيق الشيفرة، وأدوات الفحص (linters)، والإعدادات الخاصة بلغة معيّنة. وتُخزَّن إعدادات مساحة العمل في مجلد `.vscode` في جذر مساحة عملك في ملف `settings.json`. وإن لم تُحفظ مساحة العمل صراحةً، فتُخزَّن هذه الإعدادات في إعدادات المستخدم، لكن مقيّدة بالمجلدات المفتوحة.
- **إعدادات المجلد:** داخل مساحة العمل، يمكنك زيادة تخصيص الإعدادات لمجلدات محدّدة. وإعدادات المجلد هي المستوى الأكثر تفصيلًا، وهي تتجاوز إعدادات المستخدم وإعدادات مساحة العمل معًا. ومثل إعدادات مساحة العمل، تُخزَّن إعدادات المجلد في مجلد `.vscode` داخل المجلد المحدّد في ملف `settings.json`. وهذا المستوى مفيد للتكوينات المحدّدة جدًا داخل مساحة عمل كبيرة، مثل إعدادات مختلفة لمجلدي الواجهة الخلفية والأمامية في مشروع متكامل.

**أسبقية الإعدادات:** عندما يُعرَّف إعداد على مستويات متعدّدة، يطبّق Visual Studio Code الإعداد من المستوى الأكثر تحديدًا. فتتجاوز إعدادات المجلد إعدادات مساحة العمل، التي تتجاوز بدورها إعدادات المستخدم، التي تتجاوز في النهاية الإعدادات الافتراضية. ويضمن هذا النظام المتعاقب أنك تستطيع تعريف تفضيلات عامة على مستوى المستخدم ثم ضبطها بدقّة أكبر لمشاريع أو مجلدات محدّدة عند الحاجة.
