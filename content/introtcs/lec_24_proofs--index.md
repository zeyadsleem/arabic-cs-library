#  البراهين والخوارزميات  { #chapproofs }

>_«لن نحاول تعريف المعرفة، بل لنحاول تعريف المعرفة الصفرية (zero-knowledge).»_، شافي غولدواسر (Shafi Goldwasser).


_البراهين_ (proofs) شغلت خيالَ البشر لآلاف السنين، منذ صدور كتاب «العناصر» (_Elements_) لإقليدس، وهو كتابٌ لا يفوقه إلا الكتابُ المقدّس في عدد الطبعات.


المخطَّط:

* البراهين والخوارزميات

* البراهين التفاعلية (interactive proofs)

* براهين المعرفة الصفرية (zero knowledge proofs)

* المُقترَحات بوصفها أنواعًا (propositions as types)، وCoq وبراهينُ مساعدةٌ أخرى (proof assistants).
