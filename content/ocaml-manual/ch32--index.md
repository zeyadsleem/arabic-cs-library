# الفصل 32: مكتبة unix: نداءات نظام Unix

تتيح مكتبة `unix` لبرامج OCaml استعمال كثير من نداءات نظام Unix ودوال المكتبة المتصلة بالنظام. ويصف هذا الفصل بإيجاز الدوال التي توفّرها. وارجع إلى القسمين 2 و3 من دليل Unix لمزيد من التفاصيل عن سلوك هذه الدوال.

- الوحدة `Unix`: نداءات نظام Unix

- الوحدة `UnixLabels`: نداءات نظام Unix الموسومة

لا توفّر جميع صيغ Unix كل الدوال. وإذا لم تكن بعض الدوال متاحة، فإنها ترفع `Invalid_arg` عند استدعائها.

ويجب ربط البرامج التي تستعمل مكتبة `unix` على النحو التالي:

```text
        ocamlc other options -I +unix unix.cma other files
        ocamlopt other options  -I +unix unix.cmxa other files
```

ولااستعمال مكتبة `unix` استعمالًا تفاعليًا، افعل ما يلي:

```text
        ocamlmktop -o mytop -I +unix unix.cma
        ./mytop
```

أو (إذا كان الربط الدينامي لمكتبات C مدعومًا على منصّتك) ابدأ `ocaml` واكتب

```ocaml
# #directory "+unix";;

# #load "unix.cma";;
```

> Windows: تطبيق Cygwin من OCaml ينفّذ تنفيذًا كاملًا جميع دوال وحدة Unix. أما تطبيقات Win32 الأصلية فتنفّذ مجموعة جزئية منها. وفي ما يلي قائمة بالدوال التي لا تنفّذها تطبيقات Win32، أو التي تنفّذها تنفيذًا جزئيًا فقط. أما الدوال غير المذكورة فمنفَّذة تنفيذًا كاملًا وتتصرّف كما ورد سابقًا في هذا الفصل.

| --- | --- |
| `fork` | غير منفَّذة، استعمل `create_process` أو الخيوط |
| `wait` | غير منفَّذة، استعمل `waitpid` |
| `waitpid` | لا تستطيع الانتظار إلا لعملية ذات معرّف معطى، لا لأي عملية فرعية |
| `getppid` | غير منفَّذة (لا معنى لها في Windows) |
| `nice` | غير منفَّذة |
| `truncate`، `ftruncate` | منفَّذة (منذ 4.10.0) |
| `link` | منفَّذة (منذ 3.02) |
| `fchmod` | غير منفَّذة |
| `chown`، `fchown` | غير منفَّذة (لا معنى لها في نظام ملفات DOS) |
| `umask` | غير منفَّذة |
| `access` | لا يمكن اختبار إذن التنفيذ `X_OK`، بل تُختبر إذن القراءة بدلًا منه |
| `chroot` | غير منفَّذة |
| `mkfifo` | غير منفَّذة |
| `symlink`، `readlink` | منفَّذة (منذ 4.03.0) |
| `kill` | منفَّذة تنفيذًا جزئيًا (منذ 4.00.0): لا تُنفَّذ إلا الإشارة `sigkill` |
| `sigprocmask`، `sigpending`، `sigsuspend` | غير منفَّذة (لا إشارات بين العمليات في Windows) |
| `pause` | غير منفَّذة (لا إشارات بين العمليات في Windows) |
| `alarm` | غير منفَّذة |
| `times` | منفَّذة تنفيذًا جزئيًا، ولن تُبلِغ عن أزمنة العمليات الفرعية |

| `getuid`، `geteuid`، `getgid`، `getegid` | تعيد دائمًا 1 |
| `setuid`، `setgid`، `setgroups`، `initgroups` | غير منفَّذة |
| `getgroups` | تعيد دائمًا `[1]` (منذ 2.00) |
| `getpwnam`، `getpwuid` | ترفع دائمًا `Not_found` |
| `getgrnam`، `getgrgid` | ترفع دائمًا `Not_found` |
| النوع `socket_domain` | `PF_INET` مدعوم دعمًا كاملًا؛ و`PF_INET6` مدعوم دعمًا كاملًا (منذ 4.01.0)؛ و`PF_UNIX` مدعوم منذ 4.14.0، لكنه لا يعمل إلا في Windows 10 1803 وما بعده. |
| `establish_server` | غير منفَّذة؛ استعمل الخيوط |
| دوال الطرفية (`tc*`) | غير منفَّذة |
| `setsid` | غير منفَّذة |
