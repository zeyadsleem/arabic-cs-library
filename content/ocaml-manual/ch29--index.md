# الفصل 29: المكتبة الأساسية

يصف هذا الفصل المكتبة الأساسية في OCaml، وهي مؤلَّفة من تصريحات للأنواع والاستثناءات المدمجة، إضافةً إلى الوحدة `Stdlib` التي توفّر عمليات أساسية على هذه الأنواع المدمجة. وتتّسم وحدة `Stdlib` بخصيصتين:

- تُربط تلقائيًا بملفات الشيفرة الهدف للمستخدم باستعمال الأمر `ocamlc` (الفصل 13).

- تُفتح تلقائيًا عند بدء أي ترجمة، أو عند إطلاق النظام التفاعلي. لذلك يمكن استعمال معرّفات غير مؤهَّلة للإشارة إلى الدوال التي توفّرها وحدة `Stdlib`، من دون إضافة التوجيه `open Stdlib`.

## 29.1 الأنواع المدمجة والاستثناءات المعرَّفة مسبقًا

الأنواع المدمجة والاستثناءات المعرَّفة مسبقًا التالية معرَّفة دائمًا في بيئة الترجمة، لكنها ليست جزءًا من أي وحدة. وبالتالي لا يمكن الإشارة إليها إلا بأسمائها القصيرة.

### الأنواع المدمجة

```text
type int
```

> نوع الأعداد الصحيحة.

```text
type char
```

> نوع المحارف.

```text
type bytes
```

> نوع متتاليات البايتات (القابلة للكتابة).

```text
type string
```

> نوع سلاسل المحارف (التي لا يمكن تعديلها).

```text
type float
```

> نوع أعداد الفاصلة العائمة.

```text
type bool = false | true
```

> نوع القيم المنطقية (قيم الصدق).

```text
type unit = ()
```

> نوع قيمة الوحدة.

```text
type exn
```

> نوع قيم الاستثناءات.

```text
type 'a array
```

> نوع المصفوفات التي تكون عناصرها من النوع `'a`.

```text
type 'a iarray
```

> نوع المصفوفات غير القابلة للتغيير التي تكون عناصرها من النوع `'a`.

```text
type floatarray
```

> نوع المصفوفات القابلة للتغيير من أعداد الفاصلة العائمة ذات التمثيل المحزوم.

```text
type 'a list = [] | :: of 'a * 'a list
```

> نوع القوائم التي تكون عناصرها من النوع `'a`.

```text
type 'a option = None | Some of 'a
```

> نوع القيم الاختيارية من النوع `'a`.

```text
type int32
```

> نوع الأعداد الصحيحة المؤشَّرة ذات 32 بت. تُلحَق المكوّنات الحرفية للأعداد الصحيحة ذات 32 بت باللاحقة l. انظر الوحدة `Int32`.

```text
type int64
```

> نوع الأعداد الصحيحة المؤشَّرة ذات 64 بت. تُلحَق المكوّنات الحرفية للأعداد الصحيحة ذات 64 بت باللاحقة L. انظر الوحدة `Int64`.

```text
type nativeint
```

> نوع الأعداد الصحيحة المؤشَّرة الأصلية للمنصّة (32 بت على المعالجات ذات 32 بت، و64 بت على المعالجات ذات 64 بت). تُلحَق المكوّنات الحرفية للأعداد الصحيحة الأصلية باللاحقة n. انظر الوحدة `Nativeint`.

```text
type ('a, 'b, 'c, 'd, 'e, 'f) format6
```

> نوع سلاسل الصيغ. `'a` هو نوع معاملات الصيغة، و`'f` هو نوع النتيجة لدوال نمط `printf`، و`'b` هو نوع الوسيطة الأولى المعطاة لدوال الطباعة `%a` و`%t` (انظر الوحدة `Printf`)، و`'c` هو نوع نتيجة تلك الدوال، وهو أيضًا نوع الوسيطة التي تُمرَّر إلى الوسيطة الأولى لدوال نمط `kprintf`، و`'d` هو نوع النتيجة لدوال نمط `scanf` (انظر الوحدة `Scanf`)، و`'e` هو نوع دالة الاستقبال لدوال نمط `scanf`.

```text
type 'a lazy_t
```

> يُستعمل هذا النوع لتنفيذ الوحدة `Lazy`. ولا ينبغي استعماله مباشرةً.

### الاستثناءات المعرَّفة مسبقًا

```text
exception Match_failure of (string * int * int)
```

> استثناء يُرفَع عندما لا ينطبق أي من حالات مطابقة الأنماط. الوسائط هي موضع الكلمة المفتاحية `match` في الشيفرة المصدرية (اسم الملف، ورقم السطر، ورقم العمود).

```text
exception Assert_failure of (string * int * int)
```

> استثناء يُرفَع عندما يفشل تأكيد. الوسائط هي موضع الكلمة المفتاحية `assert` في الشيفرة المصدرية (اسم الملف، ورقم السطر، ورقم العمود).

```text
exception Invalid_argument of string
```

> استثناء ترفعه دوال المكتبة للإشارة إلى أن الوسائط المعطاة لا معنى لها. وتوفّر السلسلة بعض المعلومات للمبرمج. وكقاعدة عامة، لا ينبغي التقاط هذا الاستثناء، لأنه يدلّ على خطأ برمجي، وينبغي تعديل الشيفرة بحيث لا تؤدي إلى رفعه.

```text
exception Failure of string
```

> استثناء ترفعه دوال المكتبة للإشارة إلى أنها غير معرَّفة على الوسائط المعطاة. والغرض من السلسلة إعطاء بعض المعلومات للمبرمج؛ ولا يجوز *إطلاقًا* إجراء مطابقة أنماط على المكوّن الحرفي للسلسلة لأنه قد يتغيّر في إصدارات لاحقة (استعمل `Failure _` بدلًا من ذلك).

```text
exception Not_found
```

> استثناء ترفعه دوال البحث عندما يتعذّر العثور على الكائن المطلوب.

```text
exception Out_of_memory
```

> استثناء يرفعه جامع القمامة عندما لا تكفي الذاكرة لإكمال الحساب. (وهو غير موثوق بالنسبة إلى التخصيصات في الكومة الصغرى.)

```text
exception Stack_overflow
```

> استثناء يرفعه مفسّر الشيفرة البايتية عندما يبلغ مكدّس التقييم حجمه الأقصى. وهذا يدلّ غالبًا على عودية لا نهائية أو شديدة العمق في برنامج المستخدم. وقبل الإصدار 4.10، لم يكن مترجم الشيفرة الأصلية ينفّذه تنفيذًا كاملًا.

```text
exception Sys_error of string
```

> استثناء ترفعه دوال الإدخال/الإخراج للإبلاغ عن خطأ في نظام التشغيل. والغرض من السلسلة إعطاء بعض المعلومات للمبرمج؛ ولا يجوز *إطلاقًا* إجراء مطابقة أنماط على المكوّن الحرفي للسلسلة لأنه قد يتغيّر في إصدارات لاحقة (استعمل `Sys_error _` بدلًا من ذلك).

```text
exception End_of_file
```

> استثناء ترفعه دوال الإدخال للإشارة إلى الوصول إلى نهاية الملف.

```text
exception Division_by_zero
```

> استثناء ترفعه عمليات القسمة الصحيحة وحساب الباقي عندما تكون وسيطتها الثانية صفرًا.

```text
exception Sys_blocked_io
```

> حالة خاصة من `Sys_error` تُرفَع عندما لا يكون أي إدخال/إخراج ممكنًا على قناة إدخال/إخراج غير حاجبة.

```text
exception Undefined_recursive_module of (string * int * int)
```

> استثناء يُرفَع عندما يُقيَّم تعريف وحدة عودية غير مؤسَّس جيدًا. (انظر القسم 12.2.) الوسائط هي موضع التعريف في الشيفرة المصدرية (اسم الملف، ورقم السطر، ورقم العمود).
