## الشريحة 13: عدّ العمليات

- نفترض أن هذه الخطوات تستغرق زمنًا ثابتًا (Constant Time):
  - العمليات الرياضية.
  - المقارنات (Comparisons).
  - الإسنادات (Assignments).
  - الوصول إلى الكائنات في الذاكرة.
- نعدّ العمليات المنفَّذة بوصفها دالة في حجم المدخل (Input Size).

### `c_to_f`: ثلاث عمليات

```python
def c_to_f(c):
    return c*9.0/5 + 32
```

> **وصف المترجم لعلامات العدّ:** يؤطر الأصل التعبير `c*9.0/5 + 32` ويضع عليه «3 عمليات»: ضرب، وقسمة، وجمع.

### `mysum`: `1+(x+1)*(1+2) = 3x+4` عملية

```python
def mysum(x):
    total = 0
    for i in range(x+1):
        total += i
    return total
```

> **وصف المترجم لعلامات العدّ:** `total = 0` عملية واحدة. تعيين قيمة `i` في كل مرور عملية واحدة، و`total += i` عمليتان. تتكرر الحلقة `x+1` مرة.

### `square`: الصيغة المنشورة `1+n*(1)*n*(1+2) = 3n² + 1` عملية

```python
def square(n):
    sqsum = 0
    for i in range(n):
        for j in range(n):
            sqsum += 1
    return sqsum
```

> **وصف المترجم لعلامات العدّ:** التهيئة عملية واحدة؛ تعيين `i` عملية واحدة، وتعيين `j` عملية واحدة، و`sqsum += 1` عمليتان. تتكرر كل حلقة `n` مرة.

> **ملاحظة المترجم بشأن فرق في الأصل:** الصيغة المكتوبة في الشريحة هي $3n^2+1$؛ لكن احتساب تعيين `i` مرة لكل دورة خارجية، كما تفعل نسخة الكود الرسمية، يعطي $3n^2+n+1$. القيم في الشريحة 16 توافق الصيغة الثانية. كلاهما ذو رتبة نمو تربيعية، ولم تُستبدل صيغة الأصل بصمت.
