```python
def binary_search_counter(L, x):
    global count
    lo = 0
    hi = len(L)
    count += 3
    while hi-lo > 1:
        count += 2
        mid = (hi+lo) // 2
        count += 3
        if L[mid] <= x:
            lo = mid
        else:
            hi = mid
        count += 3
    count += 3
    return L[lo] == x
```

## الشريحة 43: النمو القارب (Asymptotic Growth)

- الهدف: وصف كيف ينمو الزمن مع نمو حجم المدخل
- صيغة تربط المدخل بعدد العمليات
- لدينا صيغة لعدد العمليات اللازمة لحساب خوارزمية، ونريد معرفة السلوك القارب عندما يصير حجم المسألة كبيرًا
- نريد وضع حدّ على النمو
- لا يلزم الدقة: «رتبة» وليس نموًا «دقيقًا»
- سنركّز على الحدّ (term) الذي ينمو أسرع
- نتجاهل الثوابت الجمعية والضربية، لأننا نريد أن نعرف كيف يزداد الزمن اللازم بسرعة مع زيادة حجم المدخل
- هذا ما يُسمّى **رتبة النمو (order of growth)**
- نستخدم المفاهيم الرياضية «O الكبير» (big O) و«ثيتا الكبير» (big Θ)

## الشريحة 44: تعريف O الكبير (Big O)

$$3x^2 + 20x + 1 = O(x^2)$$

- لنفترض أن شيفرة ما تعمل في $$f(x) = 3x^2 + 20x + 1$$ خطوة
- فكّر في هذا في الصيغة الناتجة عن عدّ عدد العمليات.
- **ليس** حدًّا أعلى؛ مع $$x \to \infty$$ سيتجاوزه `f(x)` دائمًا
- لن يتقاطعا أبدًا مرة أخرى!

$$g(x) = x$$

- O الكبير طريقة لوضع حدّ أعلى على نمو أي دالة
- التقاطع (Crossover)

$$4x^2 > 3x^2 + 20x + 1 \quad \forall x > 20.04$$

- $$f(x) = O(g(x))$$ يعني أن `g(x)` مضروبة في ثابت ما ستتجاوز `f(x)` دائمًا فوق عتبة ما
- **«في النهاية» (eventually)** أي فوق قيمة عتبة معيّنة من `x`

> **ملاحظة المترجم:** الشريحة في الأصل رسم بياني لمنحنيين: المنحنى البرتقالي $4x^2$ والمنحنى الأزرق $3x^2+20x+1$، مع تحديد نقطة التقاطع عند $x = 20.04$ ووسم «Never cross again!». الرسم غير مُضمَّن، ونُقلت المعادلات والوسوم.

## الشريحة 45: O الكبير رسميًا

- حدّ O الكبير هو حدّ أعلى على نمو دالة ما
- $$f(x) = O(g(x))$$ تعني أن هناك ثابتين $c_0$ و$x_0$ بحيث $$c_0 \, g(x) \ge f(x) \quad \text{لكل } x > x_0$$

**مثال:** $$f(x) = 3x^2 + 20x + 1$$

$$f(x) = O(x^2)$$ لأن $$4x^2 > 3x^2 + 20x + 1 \quad \forall x \ge 20$$

$$(c_0 = 4,\ x_0 = 20.000)$$

- التقاطع عند $x = 20.04$
- البرتقالي > الأزرق لكل $x > 20.04$
- هذان الخطان لن يتقاطعا أبدًا مرة أخرى
- $0 \le x \le 30$
- $0 \le x \le 100$

> **ملاحظة المترجم:** الأرقام `0 <= x <= 30` و`0 <= x <= 100` هما حدّا محورَي الرسم الأفقي في النسخة الموسَّعة من الشريحة. المنحنيات نفسها غير مُضمَّنة.

## الشريحة 46: تعريف ثيتا الكبير (Big Θ)

$$3x^2 - 20x - 1 = \theta(x^2)$$

- حدّ ثيتا الكبير هو حدّ أعلى **وحدّ أدنى** على نمو دالة ما
- لنفترض $$f(x) = 3x^2 - 20x - 1$$

$$f(x) = \Theta(g(x))$$ تعني:

هناك ثابتين $c_0$ و$x_0$ بحيث $$c_0 \, g(x) \ge f(x) \quad \text{لكل } x > x_0$$

**و**

هناك ثابتين $c_1$ و$x_1$ بحيث $$c_1 \, g(x) \le f(x) \quad \text{لكل } x > x_1$$

- **مثال:** $$f(x) = \Theta(x^2)$$ لأن $$4x^2 > 3x^2 - 20x - 1 \quad \forall x \ge 0 \quad (c_0 = 4,\ x_0 = 0)$$
- **و** $$2x^2 < 3x^2 - 20x - 1 \quad \forall x \ge 20 \quad (c_1 = 2,\ x_1 = 20.000)$$
- البرتقالي > الأزرق لكل $x > 0$
- الأزرق > الأخضر لكل $x > 20.04$
- هذان الخطان لن يتقاطعا أبدًا مرة أخرى
- $0 \le x \le 100$

> **ملاحظة المترجم:** الشريحة رسم بياني بثلاثة منحنيات (برتقالي $4x^2$، أزرق $f(x)$، وأخضر $2x^2$) مع تحديد التقاطعات. الرسم غير مُضمَّن. وفي النص المستخرَج يظهر الحدّ الثاني مطبوعًا هكذا «∀x ≥ 20»، بينما وسوم الرسم تقول `x > 20.04`؛ ونُقلت المعادلة كما في الأصل والوسم كما هو.

## الشريحة 47: ثيتا مقابل O

- في الممارسة، يُفضَّل حدود ثيتا لأنها «ضيّقة» (tight)
- على سبيل المثال: $$f(x) = 3x^2 - 20x - 1$$

- $$f \, x = O \, x^2 = O \, x^3 = O(2x)$$ وكل رتبة أعلى — لأنها كلّها تحدّ من أعلى
- $$f \, x = \theta \, x^2$$
- $$\ne \Theta \, x^3 \ne \Theta \, 2x$$ وكل رتبة أعلى — لأنها تحدّ من أعلى دون أن تحدّ من أدنى

## الشريحة 52: دمج أصناف التعقيد — الحلقات على التوالي (LOOPS IN SERIES)

- حلّل العبارات داخل الدوال للحصول على رتبة النمو
- طبّق بعض القواعد، وركّز على الحدّ الغالب
- **قانون الجمع لِـ $\Theta()$:**
  - يُستخدم مع العبارات المتتابعة
- $$\Theta(f(n)) + \Theta(g(n)) = \Theta(f(n) + g(n))$$
- على سبيل المثال:

```python
for i in range(n):
    print('a')       # Θ(n)

for j in range(n*n):
    print('b')       # Θ(n^2)
```

- $\Theta(n) + \Theta(n * n) = \Theta(n + n^2) = \Theta(n^2)$ بسبب حدّ $n^2$ الغالب

## الشريحة 53: دمج أصناف التعقيد — الحلقات المتداخلة (NESTED LOOPS)

- حلّل العبارات داخل الدوال للحصول على رتبة النمو
- طبّق بعض القواعد، وركّز على الحدّ الغالب
- **قانون الضرب لِـ $\Theta$:**
  - يُستخدم مع العبارات/الحلقات المتداخلة
- $$\Theta(f(n)) * \Theta(g(n)) = \Theta(f(n) * g(n))$$
- على سبيل المثال:

```python
for i in range(n):              # Θ(n)
    for j in range(n//2):       # Θ(n) لكل تكرار للحلقة الخارجية
        print('a')
```

- $\Theta(n) \times \Theta(n) = \Theta(n \times n) = \Theta(n^2)$
- الحلقة الخارجية تعمل `n` مرات والحلقة الداخلية تعمل `n` مرات لكل تكرار من الحلقة الخارجية.
