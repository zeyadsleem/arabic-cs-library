
| الفهرس | 0 | 1 | 2 |
|---|---|---|---|
| الفهرس الموجب | 0 | 1 | 2 |

- الفهرسة تبدأ دائمًا عند 0.

| التعبير | النتيجة |
|---|---|

| `s[1]` | يُقيَّم إلى `"b"` |
| `s[2]` | يُقيَّم إلى `"c"` |
| `s[3]` | محاولة فهرسة خارج الحدود، خطأ |
| `s[-1]` | يُقيَّم إلى `"c"` |
| `s[-2]` | يُقيَّم إلى `"b"` |
| `s[-3]` | يُقيَّم إلى `"a"` |

## الشريحة 8: التقطيع للحصول على سلسلة جزئية (Substring)

- يمكنك تقطيع السلاسل النصية باستخدام `[start:stop:step]`:
  - خذ المحارف من `start` حتى `stop - 1` ضمنًا.
  خُذ كل `step` من المحارف (taking every `step` characters).
- إذا أعطيت رقمين، أي `[start:stop]`، فإن `step = 1` بشكل افتراضي.
- إذا أعطيت رقمًا واحدًا، فأنت تعود إلى الفهرسة للحصول على المحرف عند موضع واحد (الشريحة السابقة).
- يمكنك أيضًا حذف الأرقام وترك نقطتين فقط (جرّب ذلك!).

## الشريحة 9: أمثلة التقطيع

- يمكنك تقطيع السلاسل النصية باستخدام `[start:stop:step]`.
- انظر إلى `step` أولًا:
  - قيمة موجبة تعني الاتجاه من اليسار إلى اليمين.
  - قيمة سالبة تعني الاتجاه من اليمين إلى اليسار.

```python
s = "abcdefgh"
```

| الفهرس الموجب | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| الفهرس السالب | -8 | -7 | -6 | -5 | -4 | -3 | -2 | -1 |

| التعبير | النتيجة |
|---|---|
| `s[3:6]` | يُقيَّم إلى `"def"`، أي ما يعادل `s[3:6:1]` |
| `s[3:6:2]` | يُقيَّم إلى `"df"` |
| `s[:]` | يُقيَّم إلى `"abcdefgh"`، أي ما يعادل `s[0:len(s):1]` |
| `s[::-1]` | يُقيَّم إلى `"hgfedcba"` |
| `s[4:1:-2]` | يُقيَّم إلى `"ec"` |

## الشريحة 11: السلاسل النصية غير قابلة للتغيير (Immutable)

- السلاسل النصية «غير قابلة للتغيير» — لا يمكن تعديلها.
- يمكنك إنشاء كائنات جديدة تكون نسخًا من الأصل.
- اسم المتغيّر لا يمكن أن يُربط إلا بكائن واحد:

```python
s = "car"
s[0] = 'b'
```

← يعطي خطأً.

```python
s = 'b'+s[1:len(s)]
```

← مسموح، و`s` مربوطة بكائن جديد.

| قبل | بعد |
|---|---|
| "car" | "bar" |

## الشريحة 26: خوارزمية مهمّة: طريقة نيوتن (Newton’s Method)

- تجد جذور متعدّد الحدود (Polynomial):

$$f(g, x) = g^3 - x = 0$$

- الخوارزمية تستخدم التقريب المتتالي (Successive Approximation):

$$next\_guess = guess - \frac{f(guess)}{f'(guess)}$$

- شيفرة جزئية من الخوارزمية تأخذ المدخلات وتجد التخمين التالي:

```python
# Try Newton Raphson for cube root
x = int(input('What x to find the cube root of? '))
g = int(input('What guess to start with? '))
print('Current estimate cubed = ', g**3)
next_g = g - ((g**3 - x)/(3*g**2))
print('Next guess to try = ', next_g)
```

## الشريحة 31: عوامل المقارنة (COMPARISON OPERATORS)

- `i` و`j` أسماء متغيّرات.
- يمكن أن تكون من نوع `int` أو `float` أو سلاسل نصية، إلخ.
- المقارنات التالية تُقيَّم إلى النوع البولياني (Boolean).
- النوع البولياني له قيمتان فقط: `True` و`False`.

| العامل | المعنى |
|---|---|
| `i > j` | أكبر من |
| `i >= j` | أكبر من أو يساوي |
| `i < j` | أصغر من |
| `i <= j` | أصغر من أو يساوي |
| `i == j` | اختبار التساوي، `True` إذا كان `i` هو نفسه `j` |
| `i != j` | اختبار عدم التساوي، `True` إذا كان `i` ليس نفسه `j` |

## الشريحة 32: العوامل المنطقية على `bool`

- `a` و`b` أسماء متغيّرات (بقيم بوليانية).
- `not a` ← `True` إذا كان `a` هو `False`، و`False` إذا كان `a` هو `True`.
- `a and b` ← `True` إذا كان كلاهما `True`.
- `a or b` ← `True` إذا كان أحدهما أو كلاهما `True`.

| A | B | A and B | A or B |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

## الشريحة 37: مخطط التفريع

- إذا كان اليمين خاليًا، فاذهب يمينًا.
- إذا كان اليمين مسدودًا والأمام خالًا، فاذهب يسارًا.

- إذا كان اليمين والأمام واليسار مسدودة، فارجع للخلف.

```text
    <code>
    <code>
    ...
else:
    <code>
    <code>
    ...
<rest of program>
```

- لـ`<condition>` قيمة `True` أو `False`.
- المسافة البادئة مهمة في بايثون!
- شغّل الكتلة الأولى التي يقابلها شرط قيمته `True`. وتُشغَّل كتلة `else` عندما لا يكون أي شرط `True`.

## الشريحة 44: المسافة البادئة والتفريع المتداخل (Nested Branching)

- المسافة البادئة مهمة في بايثون.
- هي الطريقة التي تدلّ بها على كتل الشيفرة.

```python
x = float(input("Enter a number for x: "))

if x == y:
    print("x and y are equal")
    if y != 0:
        print("therefore, x / y is", x/y)
    else:
        print("thanks!")
elif x < y:
    print("x is smaller")
else:
    print("y is smaller")
```
