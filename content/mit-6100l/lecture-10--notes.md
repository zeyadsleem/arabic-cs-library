## الشريحة 2: الفهرسة والترتيب في القوائم (Indices and Ordering in Lists)

```python
a_list = []
L = [2, 'a', 4, [1,2]]
```

| التعبير | النتيجة |
| --- | --- |
| `len(L)` | يُقيَّم إلى `4` |
| `L[0]` | يُقيَّم إلى `2` |
| `L[3]` | يُقيَّم إلى `[1,2]` — أي قائمة أخرى! |
| `[2,'a'] + [5,6]` | يُقيَّم إلى `[2,'a',5,6]` |

| `L[1:3]` | يُقيَّم إلى `['a', 4]` |
| `for e in L` | متغيّر الحلقة يأخذ كل عنصر في `L` بالترتيب |
| `L[3] = 10` | يُغيِّر (Mutates) `L` لتصبح `[2,'a',4,10]` |

## الشريحة 3: قابلية التغيير (Mutability)

- القوائم قابلة للتغيير (Mutable)!
- الإسناد إلى عنصر عند فهرس يغيّر القيمة:

```python
L = [2, 4, 3]
L[1] = 5
```

- صارت `L` الآن `[2, 5, 3]`؛ ولاحظ أن هذه هي الكائن نفسه `L`.

| الاسم | القيمة قبل | القيمة بعد |
| --- | --- | --- |
| `L` | `[2,4,3]` | `[2,5,3]` |

## الشريحة 4: قابلية التغيير — مقارنة

- قارن بين:
  - إنشاء `L` بتغيير عنصر (Mutating an Element)، و
  - إنشاء `t` بإنشاء كائن جديد (Creating a New Object).

```python
L = [2, 4, 3]
L[1] = 5

t = (2, 4, 3)
t = (2, 5, 3)
```

| الاسم | ملاحظة |
| --- | --- |
| `L` | `[2,4,3]` ثم `[2,5,3]` — الكائن نفسه تغيّر |
| `t` | `(2,4,3)` ثم `(2,5,3)` — كائن جديد، فالكائن الأول لم يتغيّر |

## الشريحة 5: العمليات على القوائم — الإلحاق (Operation on Lists — append)

## الشريحة 15: من النصوص إلى القوائم (Strings to Lists)

## الشريحة 16: من القوائم إلى النصوص (Lists to Strings)

- حوّل قائمة نصوص إلى نص.
- استعمل `''.join(L)` لتحويل قائمة نصوص إلى نص أكبر.
- يمكن تمرير محرف بين علامتَي تنصيص ليُضاف بين كل عنصرين.

```python
L = ['a','b','c']
A = ''.join(L)
B = '_'.join(L)
C = ''.join([1,2,3])
C = ''.join(['1','2','3'])
```

| التعبير | النتيجة |
| --- | --- |
| `L` | قائمة |
| `A` | `"abc"` |
| `B` | `"a_b_c"` |
| `''.join([1,2,3])` | خطأ (Error) |
| `C` | `"123"` — نص! |

**ملاحظة المترجم:** السطر الرابع في النصّ المستخرَج ناقص قوسًا إغلاقًا؛ اعتُمدت صياغته الصحيحة `''.join(['1','2','3'])` لأن الشرح يصف الناتج `"123"` نصًّا.

## الشريحة 18: بعض عمليات القوائم المهمة (A Few Interesting List Operations)

- **إضافة عنصر إلى نهاية القائمة** بـ `L.append(element)` — تُغيّر القائمة (Mutates the list).

- **`sort()`**

```python
L = [4,2,7]
L.sort()
```

  تُغيّر `L`.

- **`reverse()`**

```python
L = [4,2,7]
L.reverse()
```

  تُغيّر `L`.

- **`sorted()`**

```python
L = [4,2,7]
L_new = sorted(L)
```

  تُرجِع نسخة مرتّبة من `L` (بلا تغيير في `L`!).

## الشريحة 19: قابلية التغيير — المثال الأول (Mutability)

```python
L=[9,6,0,3]
L.append(5)

a = sorted(L) # returns a new sorted list, does not mutate L

b = L.sort() # mutates L to be [0,3,5,6,9] and returns None

L.reverse()  # mutates L to be [9,6,5,3,0] and returns None
```

| الاسم | القيمة قبل | القيمة بعد |
| --- | --- | --- |

## الشريحة 22: قابلية التغيير — تنفيذ `a = sorted(L)`

نفس الشيفرة. ظهر اسم جديد `a` في النطاق العام، و`L` صارت `[9,6,5,3,0]` بعد `reverse`:

| الاسم | القيمة |
| --- | --- |
| `a` | `[0,3,5,6,9]` — القائمة الجديدة المرتّبة |
| `b` | `None` |
| `L` | `[9,6,5,3,0]` |

**ملاحظة المترجم:** يبيّن النصّ المستخرَج أن `a` تحتفظ بنسخة `[0,3,5,6,9]` من حين استُدعيت `sorted`، بينما `L` نفسها صارت `[9,6,5,3,0]` بعد `L.reverse()`. هذا هو الفرق الجوهري بين `sorted` و`sort` و`reverse`.

## الشريحة 25: القوائم تدعم التكرار (Lists Support Iteration)

- لنكتب دالة تُغيّر مُدخلها.
- مثال: تربيع كل عنصر في قائمة، مع تغيير القائمة الأصلية.

```python
def square_list(L):
    for elem in L:
        # ?? How to do L[index] = the square ??
        # ?? elem is an element in L, not the index :(
```

- الحلول (سنتناول الخيار الثاني، جرّب البقية بنفسك):
  - **الخيار 1:** أنشئ متغيّرًا جديدًا يمثّل الفهرس، يتهيّأ إلى `0` قبل الحلقة ويزداد بمقدار `1` داخل الحلقة.
  - **الخيار 2:** مرّ على الفهرس لا على العنصر، واستعمل `L[index]` للحصول على العنصر.
  - **الخيار 3:** استعمل `enumerate` في حلقة `for` (أترك لك البحث عن هذا الخيار)، أي `for i,e in enumerate(L)`.

## الشريحة 30: التغيير (Mutation)

- القوائم بنى قابلة للتغيير (Mutable Structures).
- ولها مزايا كثيرة:
  - لنفترض أن لدي قائمة طويلة جدًا (مثلًا سجلات موظفين) وأريد تحديث عنصر واحد. بدون التغيير (Mutation) لما كنت مضطرًّا إلى نسخ القائمة كاملة، مع نسخة جديدة من ذلك السجل في الموضع الصحيح. البنية القابلة للتغيير تتيح لي تغيير ذلك العنصر وحده.
- لكن هذه القدرة قد تضيف تحدّيات غير متوقّعة.

**ملاحظة المترجم:** نُقل المعنى كاملًا، وسُبِقت كلمة «مزايا» بما يقابل `advantages` في الأصل.

## الشريحة 32: المثال الصعب 1 — الإلحاق (append)

- `range` تُرجِع شيئًا يتصرّف مثل الصف (لكنه ليس صفًّا؛ فهي تُرجِع قيمة قابلة للتكرار — Iterable).
- تُرجِع العنصر الأول، وطريقة تكرار (Iteration Method) تُولِّد بها العناصر التالية عند الحاجة.

| التعبير | المقابل التقريبي |
| --- | --- |
| `range(4)` | مثل الصف `(0,1,2,3)` |
| `range(2,9,2)` | مثل الصف `(2,4,6,8)` |

```python
L = [1,2,3,4]

for i in range(len(L)):
    L.append(i)

print(L)
```

لأن `len(L)` تُقيَّم مرة واحدة عند إنشاء كائن `range` القابل للتكرار، تتوقف الحلقة عند أربع تكرارات:

| التكرار | حالة `L` |
| --- | --- |
| الأولى | `[1, 2, 3, 4, 0]` |
| الثانية | `[1, 2, 3, 4, 0, 1]` |
| الثالثة | `[1, 2, 3, 4, 0, 1, 2]` |
| الرابعة | `[1, 2, 3, 4, 0, 1, 2, 3]` |

## الشريحة 33: المثال الصعب 1 — الرسم البياني

نفس الشيفرة، ومعها رسمة الكائنات:

| الكائن/الاسم | ملاحظة |
| --- | --- |
| `(0,1,2,3)` | كائن `range` الذي أنشأته `range(len(L))` |
| `i` | متغيّر الحلقة، قيمته `3` في التكرار الأخير |
| `L` | `[1,2,3,4,0,1,2,3]` |
| الكائن الفعلي في الذاكرة | `[1,2,3,4,0,1,2,3]` |

**ملاحظة المترجم:** الشرائح تعرض القيم على جانبي السطر: قائمة في الذاكرة وقيمة الاسم الذي يشير إليها. نُقلت الجداول أعلاه، وسطرا القائمة المبدئية `[1,2,3,4]` والقائمة النهائية `[1,2,3,4,0,1,2,3]` كلاهما حاضران في النصّ المستخرَج.

## الشريحة 34: المثال الصعب 2 — الإلحاق (append)

- يبدو مشابهًا لكن…

```python
L = [1,2,3,4]
i = 0

for e in L:
    L.append(i)
    i += 1

print(L)
```

- في المثال السابق، كان `L` يُستعمَل عند البداية لإنشاء `range` قابل للتكرار؛ وفي هذا المثال، الحلقة تصل مباشرة إلى فهارس `L`.

| التكرار | `e` | حالة `L` |
| --- | --- | --- |
| الأولى | `1` | `[1, 2, 3, 4, 0]` |
| الثانية | `2` | `[1, 2, 3, 4, 0, 1]` |
| الثالثة | `3` | `[1, 2, 3, 4, 0, 1, 2]` |
| الرابعة | `4` | `[1, 2, 3, 4, 0, 1, 2, 3]` |

**لا تتوقّف أبدًا! (NEVER STOPS!)**

**ملاحظة المترجم:** جدول القيم لـ`e` أعلاه مستخرج من الأرقام الظاهرة في شريحة الرسم البياني لهذه الشريحة. والنتيجة النهائية للحلقة لا تنتهي لأن `len` القائمة تتزايد في كل دورة؛ وهذا هو سبب تسميتها «المثال الصعب 2» في الشريحة 31.

## الشريحة 35: دمج القوائم (Combining Lists)

- الدم (Concatenation) عبر المشغّل `+` ينشئ قائمة جديدة **بنسخ** (With Copies).
- لتغيير القائمة استعمل `L.extend(some_list)` (نسخة من `some_list`).

```python
L1 = [2,1,3]
L2 = [4,5,6]
L3 = L1 + L2
```

- `L3` هي `[2,1,3,4,5,6]`.

| الاسم | القيمة |
| --- | --- |
| `L1` | `[2,1,3]` |
| `L2` | `[4,5,6]` |
| `L3` | `[2,1,3,4,5,6]` |

## الشريحة 43: إفراغ قائمة والتأكّد من أنها الكائن نفسه (Empty Out a List and Checking That It's the Same Object)

- يمكنك تغيير قائمة لإزالة كل عناصرها.
- هذا **لا ينشئ** قائمة فارغة جديدة!

استعمل `L.clear()`.

كيف تتحقّق من أنها الكائن نفسه في الذاكرة؟ استعمل الدالة `id()`.

جرّب هذا في الطرفية (Console):

```python
>>> L = [4,5,6]
>>> L.append(8)
>>> id(L)
>>> L.clear()
>>> L = []
>>> id(L)
```

**ملاحظة المترجم:** الشريحة تعرض `id(L)` بعد كل خطوة من هذه السلسلة؛ والأرقام المعروضة لقيم `id` في الأصل لم يحفظها النصّ المستخرَج، ولذلك لم تُنقل هنا ولم يُخمَّن شيء عنها. الفكرة التي يعلّمها المثال أن `L.clear()` يُبقي `id(L)` كما هو، بينما `L = []` يعطي `id` مختلفًا.

## الشريحة 44: الخلاصة (SUMMARY)

- القوائم والصفوف توفّر طريقة لتنظيم البيانات تدعم طبيعيًّا الدوال التكرارية (Iterative Functions).
- الصفوف غير قابلة للتغيير (Immutable) مثل النصوص:
  - الصفوف مفيدة حين تكون لديك بيانات لا تحتاج إلى تغيير، مثل `(خط العرض، خط الطول)` أو `(رقم الصفحة، رقم السطر)`.
- القوائم قابلة للتغيير (Mutable):
  - يمكنك تعديل الكائن بتغيير عنصر عند فهرس.
  - يمكنك تعديل الكائن بإضافة عناصر إلى النهاية.
  - سنرى عمليات كثيرة أخرى على القوائم في المحاضرة القادمة.
  - القوائم مفيدة في الحالات الديناميكية، مثل قائمة أفضل 40 أغنية يوميًا أو قائمة الأفلام التي شُوهدت مؤخّرًا.
