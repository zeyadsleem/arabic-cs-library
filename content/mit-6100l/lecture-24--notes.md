## الشريحة 2: البحث في قائمة مرتّبة — حيث `n` هو `len(L)`

- باستخدام البحث الخطّي، البحث عن عنصر هو $\Theta(n)$.
- باستخدام البحث الثنائي، يمكننا البحث عن عنصر في $\Theta(\log n)$ — بافتراض أن القائمة مرتّبة!
- متى يكون من المعقول أن نرتب أولًا ثم نبحث؟

$$SORT + \Theta(\log n) < \Theta(n)$$

$$\Rightarrow SORT < \Theta(n) - \Theta(\log n)$$

«متى يكون الترتيب أصغر من $\Theta(n)$؟!؟ هذا لا يحدث أبدًا!»

## الشريحة 3: التكلفة المُطفَّرة (Amortized Cost) — حيث `n` هو `len(L)`

- لماذا نرتّب أولًا إذن؟
- رتّب القائمة مرّة واحدة ثم أجرِ عمليات بحث كثيرة.
- نُطفئ (amortize) كلفة الترتيب على عمليات البحث الكثيرة.
- $SORT + K * \Theta(\log n) < K * \Theta(n)$، أي إن كان `K` كبيرًا فإن زمن الترتيب يصبح غير ذي أثر.

## الشريحة 6: تعقيد الترتيب العشوائي (Bogo Sort)

```python
def bogo_sort(L):
    while not is_sorted(L):
        random.shuffle(L)
```

- أفضل حالة: $\Theta(n)$ حيث $n$ هو `len(L)`، للتحقّق من كون القائمة مرتّبة.
- أسوأ حالة: $\Theta(?)$ — فهي غير محدودة (unbounded) إن كانت الحظّ سيّئًا جدًّا.

## الشريحة 7: الترتيب الفقاعي (Bubble Sort)

- قارن أزواجًا متتالية من العناصر.
- بدّل العنصرين في كل زوج بحيث يكون الأصغر أولًا.
- عند بلوغ نهاية القائمة، ابدأ من جديد.
- توقّف عندما لا تُجرى أي مبادلات (swaps) بعد اليوم.

> «يبدو للترتيب الفقاعي (bubble sort) أنه لا شيء يروّج له، إلا اسمًا سهل التلقّي وحقيقة أنه يقود إلى بعض المسائل النظرية المثيرة».

## الشريحة 8: تعقيد الترتيب الفقاعي

```python
def bubble_sort(L):
    did_swap = True
    while did_swap:
        did_swap = False
        for j in range(1, len(L)):
            if L[j-1] > L[j]:
                did_swap = True
                L[j],L[j-1] = L[j-1],L[j]
```

- الحلقة `for` الداخلية تُجري المقارنات.
- الحلقة `while` الخارجية تُجري عدّة تمريرات (passes) حتى تصير المبادلات معدومة.
- $\Theta(n^2)$ حيث $n$ هو `len(L)`، يلزم `len(L)-1` مقارنة و `len(L)-1` تمريرة.

## الشريحة 9: الترتيب بالاختيار (Selection Sort)

**الخطوة الأولى:**
- استخرج العنصر الأصغر (minimum element).
- بدّله مع العنصر الموجود عند الفهرس 0.

**الخطوة الثانية:**
- في القائمة الفرعية المتبقّية، استخرج العنصر الأصغر.
- بدّله مع العنصر الموجود عند الفهرس 1.

**احتفظ بالجزء الأيسر من القائمة مرتّبًا:**
- عند الخطوة `i`، تكون أول `i` عناصر في القائمة مرتّبة، وكل العناصر الأخرى أكبر من هذه العناصر الأولى.

## الشريحة 10: تعقيد الترتيب بالاختيار

```python
def selection_sort(L):
    for i in range(len(L)):
        for j in range(i, len(L)):
            if L[j] < L[i]:
                L[i], L[j] = L[j], L[i]
```

- تعقيد الترتيب بالاختيار هو $\Theta(n^2)$ حيث $n$ هو `len(L)`.
- الحلقة الخارجية تُنفَّذ `len(L)` مرّة.
- الحلقة الداخلية تُنفَّذ `len(L) – i` مرّة، أي `len(L)/2` في المتوسط.
- ويمكن أيضًا التفكير في عدد مرات المقارنة عبر الحلقتين معًا: لنفرض $n = len(L)$:

$$1 + 2 + 3 + \dots + n = (n)(n+1)/2 = n^2/2 + n/2 = \Theta(n^2)$$

## الشريحة 12: الترتيب بالدمج (Merge Sort)

استخدِم منهج «اقسم وانتصر» (divide-and-conquer):

- إذا كان طول القائمة 0 أو 1 فهي مرتّبة أصلًا.
- إذا كان في القائمة أكثر من عنصر:
  - قسّمها إلى قائمتين، ورتّب كلًّا منهما.
  - ادمج القائمتين الفرعيتين المرتّبتين:
    - انظر إلى العنصر الأول من كلٍّ منهما، وانقل الأصغر إلى نهاية النتيجة.
    - عندما تفرغ إحدى القائمتين، انسخ بقيّة الأخرى.

## الشريحة 13: الترتيب بالدمج — «اقسم وانتصر»

## الشريحة 20: خطوة دمج القوائم الفرعية

```python
def merge(left, right):
    result = []
    i,j = 0, 0
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    while (i < len(left)):
        result.append(left[i])
        i += 1
    while (j < len(right)):
        result.append(right[j])
        j += 1
    return result
```

## الشريحة 22: خوارزمية الترتيب بالدمج كاملة — بالاستدعاء الذاتي

```python
def merge_sort(L):
    if len(L) < 2:
        return L[:]
    else:
        middle = len(L)//2
        left = merge_sort(L[:middle])
        right = merge_sort(L[middle:])
        return merge(left, right)
```

- يقسم القائمة تباعًا إلى أنصاف.
- يسير بعمق أولًا (depth-first) بحيث يخضع أصغر القطع في فرع واحد قبل الانتقال إلى قطع أكبر.

## الشريحة 24: تعقيد الترتيب بالدمج

**كل مستوى:**

- **عند مستوى الاستدعاء الذاتي الأول:**
  - $n/2$ عنصرًا في كل قائمة، وقائمتان.
  - دمج واحد $\Rightarrow \Theta(n) + \Theta(n) = \Theta(n)$ حيث $n$ هو `len(L)`.
- **عند مستوى الاستدعاء الذاتي الثاني:**
  - $n/4$ عنصرًا في كل قائمة، وأربع قوائم.
  - دمجان $\Rightarrow \Theta(n)$ حيث $n$ هو `len(L)`.
- وهكذا…

**عدد المستويات:**

- تقسيم القائمة إلى نصفين عند كل استدعاء ذاتي يعطينا مستوياتنا:
  - $\Theta(\log n)$ حيث $n$ هو `len(L)`.
  - مثل البحث بالتنصيف: $1 = n/2^i$ تخبرنا بعدد التقسيمات المطلوبة للوصول إلى عنصر واحد.

**الإجمالي:** كل مستوى استدعاء ذاتي يؤدّي $\Theta(n)$ من العمل، وعدد المستويات $\Theta(\log n)$، حيث $n$ هو `len(L)`. إذن التعقيد الإجمالي هو:

$$\Theta(n \log n) \text{ حيث } n = len(L)$$

## الشريحة 25: خلاصة خوارزميات الترتيب — حيث `n` هو `len(L)`

| الخوارزمية | التعقيد | ملاحظة |
|---|---|---|
| الترتيب العشوائي (Bogo sort) | $\Theta(?)$ غير محدود | عشوائية |
| الترتيب الفقاعي (Bubble sort) | $\Theta(n^2)$ | |
| الترتيب بالاختيار (Selection sort) | $\Theta(n^2)$ | يضمن أنّ أول `i` عناصر كانت مرتّبة |
| الترتيب بالدمج (Merge sort) | $\Theta(n \log n)$ | |

$\Theta(n \log n)$ هو أسرع ما يمكن أن يكون عليه أي ترتيب.
