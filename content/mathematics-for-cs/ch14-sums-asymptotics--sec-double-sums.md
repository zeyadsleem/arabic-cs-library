# المجاميع المزدوجة

أحيانًا نضطرّ إلى تقييم مجاميع لمجاميع، وتُعرف أيضًا بالمجاميع المزدوجة. يبدو هذا شائكًا، وهو كذلك أحيانًا. لكنه عادةً مباشر — تقيّم المجموع الداخلي، وتستبدله بصيغة مغلقة، ثم تقيّم المجموع الخارجي (الذي لم يبقَ داخله مجموع). فمثلًا، بتطبيق المعادلة (١٤.٢) ثم المبرهنة ١٤.١.١ نحصل على:[^hairy]

\[
\begin{aligned}
\sum_{n=0}^{\infty} y^n \sum_{i=0}^{n} x^i
&= \sum_{n=0}^{\infty} y^n\left(\frac{1 - x^{n+1}}{1 - x}\right) \\
&= \left(\frac{1}{1-x}\right)\sum_{n=0}^{\infty} y^n - \left(\frac{1}{1-x}\right)\sum_{n=0}^{\infty} y^n x^{n+1} \\
&= \frac{1}{(1-x)(1-y)} - \left(\frac{x}{1-x}\right)\sum_{n=0}^{\infty} (xy)^n \\
&= \frac{1}{(1-x)(1-y)} - \frac{x}{(1-x)(1-xy)} \\
&= \frac{(1-xy) - x(1-y)}{(1-x)(1-y)(1-xy)} \\
&= \frac{1-x}{(1-x)(1-y)(1-xy)} \\
&= \frac{1}{(1-y)(1-xy)}.
\end{aligned}
\]

[^hairy]: حسنًا، ربما هذا المثال شائك قليلًا، لكنه مباشر إلى حدّ كبير أيضًا. انتظر حتى ترى المثال التالي!

وحين لا توجد صيغة مغلقة واضحة للمجموع الداخلي، فثمّة حيلة خاصة كثيرًا ما تكون مفيدة، هي محاولة تبادل ترتيب الجمع. فمثلًا، لنفترض أننا نريد حساب مجموع الأعداد التوافقية \(n\) الأولى:

\[
\sum_{k=1}^{n} H_k = \sum_{k=1}^{n} \sum_{j=1}^{k} \frac{1}{j}. \tag{14.27}
\]

وللحصول على حدس عن هذا المجموع، يمكننا تطبيق المبرهنة ١٤.٣.٢ على المعادلة (١٤.٢١) لنستنتج أن المجموع قريب من

\[
\int_{1}^{n} \ln(x)\,dx = \left.x\ln(x) - x\right|_{1}^{n} = n\ln(n) - n + 1.
\]

والآن لنبحث عن إجابة دقيقة. إذا فكّرنا في الأزواج \((k, j)\) التي نجمع عليها، فإنها تشكّل مثلثًا:

| \(j\) | 1 | 2 | 3 | 4 | 5 | … | \(n\) |
|---|---|---|---|---|---|---|---|
| \(k=1\) | 1 | | | | | | |
| \(k=2\) | 1 | 1/2 | | | | | |
| \(k=3\) | 1 | 1/2 | 1/3 | | | | |
| \(k=4\) | 1 | 1/2 | 1/3 | 1/4 | | | |
| ⋮ | | | | | | | |
| \(k=n\) | 1 | 1/2 | | … | | | 1/n |

المجموع في المعادلة (١٤.٢٧) يجمع كل صفّ ثم يجمع مجاميع الصفوف. وبدلًا من ذلك يمكننا أن نجمع الأعمدة ثم نجمع مجاميع الأعمدة. وبفحص الجدول نرى أن هذا المجموع المزدوج يمكن كتابته على الصورة

\[
\begin{aligned}
\sum_{k=1}^{n} H_k
&= \sum_{k=1}^{n} \sum_{j=1}^{k} \frac{1}{j} \\
&= \sum_{j=1}^{n} \sum_{k=j}^{n} \frac{1}{j} \\
&= \sum_{j=1}^{n} \frac{1}{j} \sum_{k=j}^{n} 1 \\
&= \sum_{j=1}^{n} \frac{1}{j}(n - j + 1) \\
&= \sum_{j=1}^{n} \frac{n+1}{j} - \sum_{j=1}^{n} \frac{j}{j} \\
&= (n+1)\sum_{j=1}^{n} \frac{1}{j} - \sum_{j=1}^{n} 1 \\
&= (n+1)H_n - n. \tag{14.28}
\end{aligned}
\]
