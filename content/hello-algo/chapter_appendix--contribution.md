نظراً لمحدودية القدرات، قد يغيب عن هذا الكتاب بعض المحتوى أو تعتريه أخطاء لا مفر منها. ونحن نقدّر تفهّمك، ونشكر لك مساعدتك في تصحيحها. وإذا اكتشفت أخطاء مطبعية أو روابط معطّلة أو محتوى ناقصاً أو صياغة غامضة أو شرحاً غير واضح أو مشكلات في البنية، فنرجو أن تساعدنا في تصحيحها لنقدّم للقراء موارد تعليمية أعلى جودة.

ستُعرض معرّفات GitHub الخاصة بجميع [المساهمين](https://github.com/krahets/hello-algo/graphs/contributors) في الصفحة الرئيسية لمستودع الكتاب، وفي النسخة الإلكترونية، وفي نسخة PDF، تقديراً لمساهماتهم غير الأنانية في مجتمع المصادر المفتوحة.

<div class="note">

أما في هذا الكتاب مفتوح المصدر، فقد تقلّص زمن تحديث المحتوى إلى بضعة أيام أو حتى ساعات فحسب.

### تعديلات بسيطة على المحتوى

كما يوضح الشكل أدناه، توجد «أيقونة تعديل» في الزاوية العلوية اليمنى من كل صفحة. ويمكنك تعديل النص أو الشيفرة باتباع الخطوات التالية.

1. انقر «أيقونة التعديل». وإذا ظهرت لك رسالة تطلب منك «إنشاء نسخة متفرعة (Fork) من هذا المستودع»، فوافق على العملية.
2. عدّل محتوى ملف المصدر بصيغة Markdown، وتحقق من صحة المحتوى، وحافظ على اتساق التنسيق قدر الإمكان.
3. اكتب وصفاً لتعديلاتك في أسفل الصفحة، ثم انقر زر «Propose file change». وبعد تحميل الصفحة الجديدة، انقر زر «Create pull request» لإرسال طلب السحب (pull request).

![زر تعديل الصفحة](/images/hello-algo/chapter_appendix--edit_markdown.png)

لا يمكن تعديل الصور مباشرةً. لذا يرجى وصف المشكلة بإنشاء [Issue](https://github.com/krahets/hello-algo/issues) جديد أو بترك تعليق. وسنعيد رسم الصور واستبدالها في أقرب وقت.

### إنشاء المحتوى

إذا كنت مهتماً بالمساهمة في هذا المشروع مفتوح المصدر، سواء بترجمة الشيفرة إلى لغات برمجة أخرى أو بتوسيع محتوى المقالات، فستحتاج إلى اتباع سير عمل طلب السحب (Pull Request) أدناه.

1. سجّل الدخول إلى GitHub وفرّع (Fork) [مستودع شيفرة](https://github.com/krahets/hello-algo) الكتاب إلى حسابك الشخصي.
2. انتقل إلى صفحة مستودعك المتفرع، واستخدم الأمر `git clone` لاستنساخ المستودع إلى جهازك المحلي.
3. أنشئ المحتوى محلياً وأجرِ اختبارات شاملة للتحقق من صحة الشيفرة.
4. ثبّت التغييرات المحلية وادفعها إلى المستودع البعيد.
5. حدّث صفحة المستودع وانقر زر «Create pull request» لإرسال طلب السحب.

### النشر باستخدام Docker

من الدليل الجذري لـ `hello-algo`، نفّذ أمر Docker التالي للوصول إلى المشروع على `http://localhost:8000`:

```shell
docker-compose up -d
```

واستخدم الأمر التالي لإزالة النشر:

```shell
docker-compose down
```
