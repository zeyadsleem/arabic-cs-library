إن API الخاص بـ Hono بسيط.
مكوَّن فقط من كائنات موسَّعة من معايير الويب (Web Standards).
حتى تتمكن من فهمه جيدًا بسرعة.

في هذا القسم، نقدّم واجهة برمجة تطبيقات (API) الخاصة بـ Hono كما يلي.

- كائن Hono
- حول التوجيه
- كائن السياق
- حول البرمجيات الوسيطة
