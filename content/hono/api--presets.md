لدى Hono عدة موجّهات (routers)، كل منها مُصمَّم لغرض محدد.
يمكنك تحديد الموجّه (router) الذي تريد استخدامه في مُنشئ (constructor) Hono.

**تُوفَّر قوالب جاهزة (Presets)** لحالات الاستخدام الشائعة، لذلك لا يتعين عليك تحديد الموجّه في كل مرة.
الـ `Hono` الكلاس المستورد من جميع القوالب الجاهزة (presets) هو نفسه، والفرق الوحيد هو الموجّه.
لذلك، يمكنك استخدامها بالتبادل.

## `hono`

الاستخدام:

```ts twoslash
import { Hono } from 'hono'
```

الموجِّهات:

```ts
this.router = new SmartRouter({
  routers: [new RegExpRouter(), new TrieRouter()],
})
```

## `hono/quick`

الاستخدام:

```ts twoslash
import { Hono } from 'hono/quick'
```

الموجِّه:

```ts
this.router = new SmartRouter({
  routers: [new LinearRouter(), new TrieRouter()],
})
```

## `hono/tiny`

الاستخدام:

```ts twoslash
import { Hono } from 'hono/tiny'
```

الموجِّه:

```ts
this.router = new PatternRouter()
```

## أي إعداد مسبق يجب أن أستخدم؟

| الإعداد المسبق (Preset) | المنصات المناسبة |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hono`       | هذا موصى به بشدة لمعظم حالات الاستخدام. على الرغم من أن مرحلة التسجيل قد تكون أبطأ من `hono/quick`، فإنه يُظهر أداءً عاليًا بمجرد تشغيله. إنه مثالي للخوادم طويلة العمر المبنية بـ **Deno** أو **Bun** أو **Node.js**. وهو مناسب أيضًا لـ **Fastly Compute**، حيث يحدث تسجيل المسار أثناء مرحلة بناء التطبيق على تلك المنصة. بالنسبة لبيئات مثل **Cloudflare Workers** و **Deno Deploy** حيث تُستخدم عوازل v8 (isolates)، فإن هذا الإعداد المسبق مناسب أيضًا لأن العوازل تستمر لفترة معينة من الوقت بعد التشغيل. |
| `hono/quick` | هذا الإعداد المسبق مصمم للبيئات التي تتم فيها تهيئة التطبيق لكل طلب. |
| `hono/tiny`  | هذه هي أصغر حزمة موجه (router) وهي مناسبة للبيئات ذات الموارد المحدودة. |
