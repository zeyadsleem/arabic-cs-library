للمساعدة الفورية، اسأل الـ gophers المعاونين في [خادم Slack](https://invite.slack.golangbridge.org/) الذي يديره المجتمع (احصل على دعوة منه).

والقائمة البريدية الرسمية للنقاش حول لغة Go هي [Go Nuts](https://groups.google.com/forum/#!forum/golang-nuts).

وأبلغ عن الأخطاء عبر [متتبّع مشكلات Go](https://github.com/golang/go/issues).
