الفهرس الثانوي فهرس يشير إلى [فهرس عنقودي](/book/use-the-index-luke/sql-glossary-clustered-index/index) (في SQL Server وMySQL/InnoDB) أو إلى [جدول منظَّم بالفهرس](/book/use-the-index-luke/sql-glossary-index-organized-table/index) (في Oracle). وبعبارة أخرى: فهرس على فهرس.

والوصول إلى بيانات الجدول عبر فهرس ثانوي أبطأ من استعلام مشابه على [جدول كومة](/book/use-the-index-luke/sql-glossary-heap-table/index).

- المسرد: [فهرس عنقودي](/book/use-the-index-luke/sql-glossary-clustered-index/index) — جدول مخزّن في فهرس شجرة B
