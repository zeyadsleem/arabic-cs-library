Proofs

البراهين والخوارزميات { #chapproofs }

البراهين والخوارزميات { #chapproofs }

«لن نحاول تعريف المعرفة، بل لنحاول تعريف المعرفة الصفرية (zero-knowledge).»، شافي غولدواسر (Shafi Goldwasser).

البراهين (proofs) شغلت خيالَ البشر لآلاف السنين، منذ صدور كتاب «العناصر» (Elements) لإقليدس، وهو كتابٌ لا يفوقه إلا الكتابُ المقدّس في عدد الطبعات.

المخطَّط:

  • البراهين والخوارزميات

  • البراهين التفاعلية (interactive proofs)

  • براهين المعرفة الصفرية (zero knowledge proofs)

  • المُقترَحات بوصفها أنواعًا (propositions as types)، وCoq وبراهينُ مساعدةٌ أخرى (proof assistants).
