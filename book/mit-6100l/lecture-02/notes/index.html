الشريحة 2: مراجعة

  • الكائنات (Objects):
    • الكائنات في الذاكرة لها أنواع.
    • الأنواع تخبر بايثون ما العمليات التي يمكنك إجراؤها على الكائنات.
    • التعابير تُقيَّم إلى قيمة واحدة، وتشمل كائنات وعمليات.
    • المتغيّرات تربط الأسماء بالكائنات.
    • علامة = هي إسناد، مثل var = type(5*4):
var = type(5*4)

النتيجة: var مربوطة بالقيمة int.

  • البرامج (Programs):
    • البرامج لا تفعل إلا ما تأمرها به.
    • أسطر الشيفرة تُنفَّذ بالترتيب.
    • أسماء المتغيّرات الجيدة والتعليقات تساعدك على قراءة الشيفرة لاحقًا.

مثال المراجعة:

pi = 3.14
radius = 2.2
area = pi*(radius**2)
radius = radius+1
المتغيّر القيمة
pi 3.14
radius 2.2
radius بعد إعادة الربط 3.2
area 15.1976

(STRINGS)

الشريحة 4: السلاسل النصية

  • تخيّل السلسلة str على أنها تسلسل من محارف حسّاسة لحالة الأحرف (Case Sensitive):
    • حروف، ومحارف خاصة، ومسافات، وأرقام.
  • تُحصر بين علامتَي تنصيص مزدوجتين (Quotation Marks) أو علامتَي تنصيص مفردتين.
    • يكفي أن تكون متّسقة في استخدام علامتَي التنصيص:
a = "me"
z = 'you'
  • يمكنك دمج السلاسل النصية وتكرارها:
b = "myself"
c = a + b
d = a + " " + b
silly = a * 3
المتغيّر القيمة
a "me"
b "myself"
c "memyself"
d "me myself"
silly "mememe"

الشريحة 5: جرّب بنفسك!

ما قيمتا s1 وs2؟

b = ":"
c = ")"
s1 = b + 2*c

f = "a"
g = " b"
h = "3"
s2 = (f+g)*int(h)

الشريحة 6: عمليات السلاسل النصية

  • الدالة len() دالة تُستخدم لجلب طول السلسلة النصية بين الأقواس:
s = "abc"
len(s)      # تُقيَّم إلى 3
chars = len(s)

الشريحة 7: التقطيع (Slicing) للحصول على محرف واحد في سلسلة نصية

  • تُستخدم الأقواس المربّعة (Square Brackets) لإجراء الفهرسة (Indexing) داخل السلسلة النصية للحصول على القيمة عند فهرس/موضع معيّن:
s = "abc"
الفهرس 0 1 2
الفهرس الموجب 0 1 2
الفهرس السالب -3 -2 -1
  • الفهرسة تبدأ دائمًا عند 0.
  • فهرس آخر عنصر هو len(s) - 1 أي -1.
التعبير النتيجة
s[0] يُقيَّم إلى "a"
s[1] يُقيَّم إلى "b"
s[2] يُقيَّم إلى "c"
s[3] محاولة فهرسة خارج الحدود، خطأ
s[-1] يُقيَّم إلى "c"
s[-2] يُقيَّم إلى "b"
s[-3] يُقيَّم إلى "a"

الشريحة 8: التقطيع للحصول على سلسلة جزئية (Substring)

  • يمكنك تقطيع السلاسل النصية باستخدام [start:stop:step]:
    • خذ المحارف من start حتى stop - 1 ضمنًا. خُذ كل step من المحارف (taking every step characters).
  • إذا أعطيت رقمين، أي [start:stop]، فإن step = 1 بشكل افتراضي.
  • إذا أعطيت رقمًا واحدًا، فأنت تعود إلى الفهرسة للحصول على المحرف عند موضع واحد (الشريحة السابقة).
  • يمكنك أيضًا حذف الأرقام وترك نقطتين فقط (جرّب ذلك!).

الشريحة 9: أمثلة التقطيع

  • يمكنك تقطيع السلاسل النصية باستخدام [start:stop:step].
  • انظر إلى step أولًا:
    • قيمة موجبة تعني الاتجاه من اليسار إلى اليمين.
    • قيمة سالبة تعني الاتجاه من اليمين إلى اليسار.
s = "abcdefgh"
الفهرس الموجب 0 1 2 3 4 5 6 7
الفهرس السالب -8 -7 -6 -5 -4 -3 -2 -1
التعبير النتيجة
s[3:6] يُقيَّم إلى "def"، أي ما يعادل s[3:6:1]
s[3:6:2] يُقيَّم إلى "df"
s[:] يُقيَّم إلى "abcdefgh"، أي ما يعادل s[0:len(s):1]
s[::-1] يُقيَّم إلى "hgfedcba"
s[4:1:-2] يُقيَّم إلى "ec"

الشريحة 10: جرّب بنفسك!

s = "ABC d3f ghi"

الشريحة 11: السلاسل النصية غير قابلة للتغيير (Immutable)

  • السلاسل النصية «غير قابلة للتغيير» — لا يمكن تعديلها.
  • يمكنك إنشاء كائنات جديدة تكون نسخًا من الأصل.
  • اسم المتغيّر لا يمكن أن يُربط إلا بكائن واحد:
s = "car"
s[0] = 'b'

← يعطي خطأً.

s = 'b'+s[1:len(s)]

← مسموح، وs مربوطة بكائن جديد.

قبل بعد
"car" "bar"

الشريحة 26: خوارزمية مهمّة: طريقة نيوتن (Newton’s Method)

  • تجد جذور متعدّد الحدود (Polynomial):
f(g,x)=g3−x=0f(g, x) = g^3 - x = 0f(g,x)=g3−x=0
  • الخوارزمية تستخدم التقريب المتتالي (Successive Approximation):
next_guess=guess−f(guess)f′(guess)next\_guess = guess - \frac{f(guess)}{f'(guess)}next_guess=guess−f′(guess)f(guess)​
  • شيفرة جزئية من الخوارزمية تأخذ المدخلات وتجد التخمين التالي:
# Try Newton Raphson for cube root
x = int(input('What x to find the cube root of? '))
g = int(input('What guess to start with? '))
print('Current estimate cubed = ', g**3)
next_g = g - ((g**3 - x)/(3*g**2))
print('Next guess to try = ', next_g)

الشريحة 31: عوامل المقارنة (COMPARISON OPERATORS)

  • يمكن أن تكون من نوع int أو float أو سلاسل نصية، إلخ.
  • المقارنات التالية تُقيَّم إلى النوع البولياني (Boolean).
  • النوع البولياني له قيمتان فقط: True وFalse.

الشريحة 32: العوامل المنطقية على bool

  • a وb أسماء متغيّرات (بقيم بوليانية).
  • not a ← True إذا كان a هو False، وFalse إذا كان a هو True.
  • a and b ← True إذا كان كلاهما True.
  • a or b ← True إذا كان أحدهما أو كلاهما True.
A B A and B A or B
True True True True
True False False True
False True False True
False False False False
