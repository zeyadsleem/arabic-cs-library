مسألة القطع بأقصى حاصل ضرب

في هذا القسم

  • تحديد الاستراتيجية الجشعة
  • تنفيذ الشيفرة
  • إثبات الصحة

بمعطى عدد صحيح موجب nnn، قطّعه إلى مجموع عددين صحيحين موجبين على الأقل، وأوجد أكبر حاصل ضرب للأعداد الناتجة، كما يوضح الشكل أدناه.

لنفترض أننا قطّعنا nnn إلى mmm من العوامل الصحيحة، حيث يُرمز إلى العامل رقم iii بـnin_ini​، أي

n=∑i=1mni n = \sum_{i=1}^{m}n_i n=i=1∑m​ni​

هدف هذه المسألة هو إيجاد أكبر حاصل ضرب لجميع العوامل الصحيحة، أي

max⁡(∏i=1mni) \max(\prod_{i=1}^{m}n_i) max(i=1∏m​ni​)

نحتاج إلى تحديد عدد الأجزاء mmm وما ينبغي أن تكون عليه كل nin_ini​.

تحديد الاستراتيجية الجشعة

كقاعدة عامة، كثيراً ما يكون حاصل ضرب عددين أكبر من مجموعهما. لنفترض أننا قطعنا عاملاً قدره 222 من nnn؛ فيكون حاصل الضرب الناتج 2(n−2)2(n-2)2(n−2). ولنقارن هذا الحاصل مع nnn:

2(n−2)≥n2n−n−4≥0n≥4 \begin{aligned} 2(n-2) & \geq n \newline 2n - n - 4 & \geq 0 \newline n & \geq 4 \end{aligned} 2(n−2)2n−n−4n​≥n≥0≥4​

كما يوضح الشكل أدناه، عندما n≥4n \geq 4n≥4، فإن اقتطاع 222 سيزيد حاصل الضرب، وهذا يدل على أن الأعداد الصحيحة الأكبر من أو التي تساوي 444 ينبغي أن تُقطَّع جميعها.

الاستراتيجية الجشعة الأولى: إذا احتوى مخطط القطع على عامل ≥4\geq 4≥4، فينبغي تقطيعه أكثر. ويجب ألا يحتوي مخطط القطع النهائي إلا على العوامل 111 و222 و333.

بعد ذلك، لننظر في أي عامل هو الأفضل. بين العوامل الثلاثة 111 و222 و333، من الواضح أن 111 هو الأسوأ، لأن 1×(n−1)<n1 \times (n-1) < n1×(n−1)<n يظل صحيحاً دائماً، أي أن اقتطاع 111 سيقلل حاصل الضرب فعلاً.

كما يوضح الشكل أدناه، عندما n=6n = 6n=6، لدينا 3×3>2×2×23 \times 3 > 2 \times 2 \times 23×3>2×2×2. وهذا يعني أن اقتطاع 333 أفضل من اقتطاع 222.

الاستراتيجية الجشعة الثانية: ينبغي ألا يحتوي مخطط القطع على أكثر من عاملي 222، لأن ثلاثة عوامل من 222 يمكن دائماً استبدالها بعاملين من 333 للحصول على حاصل ضرب أكبر.

وخلاصة القول، يمكن اشتقاق الاستراتيجيات الجشعة التالية.

  1. بمعطى عدد صحيح nnn، اقطع العامل 333 باستمرار حتى يصبح الباقي 000 أو 111 أو 222.
  2. عندما يكون الباقي 000، فهذا يعني أن nnn مضاعف للعدد 333، فلا حاجة إلى أي إجراء آخر.
  3. عندما يكون الباقي 222، لا تقطعه أكثر؛ اتركه كما هو.
  4. عندما يكون الباقي 111، بما أن 2×2>1×32 \times 2 > 1 \times 32×2>1×3، استبدل آخر 333 والباقي 111 بعاملين من 222.

تنفيذ الشيفرة

كما يوضح الشكل أدناه، لا نحتاج إلى حلقات لتقطيع العدد. بل نستخدم القسمة الصحيحة للحصول على عدد العوامل 333، ويُرمز إليه بـaaa، ونستخدم عملية باقي القسمة للحصول على الباقي bbb، فنحصل على:

n=3a+b n = 3 a + b n=3a+b

يرجى ملاحظة أنه في الحالة الحدية n≤3n \leq 3n≤3، يجب اقتطاع 111، ليكون حاصل الضرب 1×(n−1)1 \times (n - 1)1×(n−1).

Go

/* مسألة القطع بأقصى حاصل ضرب: خوارزمية جشعة */
func maxProductCutting(n int) int {
	// عندما n <= 3، يجب قطع 1
	if n <= 3 {
		return 1 * (n - 1)
	}
	// اقطع 3 جشعاً، a هو عدد العوامل 3 وb هو الباقي
	a := n / 3
	b := n % 3
	if b == 1 {
		// عندما يكون الباقي 1، حوّل الزوج 1 * 3 إلى 2 * 2
		return int(math.Pow(3, float64(a-1))) * 2 * 2
	}
	if b == 2 {
		// عندما يكون الباقي 2، لا تفعل شيئاً
		return int(math.Pow(3, float64(a))) * 2
	}
	// عندما يكون الباقي 0، لا تفعل شيئاً
	return int(math.Pow(3, float64(a)))
}

TypeScript

/* مسألة القطع بأقصى حاصل ضرب: خوارزمية جشعة */
function maxProductCutting(n: number): number {
    // عندما n <= 3، يجب قطع 1
    if (n <= 3) {
        return 1 * (n - 1);
    }
    // اقطع 3 جشعاً، a هو عدد العوامل 3 وb هو الباقي
    let a: number = Math.floor(n / 3);
    let b: number = n % 3;
    if (b === 1) {
        // عندما يكون الباقي 1، حوّل الزوج 1 * 3 إلى 2 * 2
        return Math.pow(3, a - 1) * 2 * 2;
    }
    if (b === 2) {
        // عندما يكون الباقي 2، لا تفعل شيئاً
        return Math.pow(3, a) * 2;
    }
    // عندما يكون الباقي 0، لا تفعل شيئاً
    return Math.pow(3, a);
}

يعتمد التعقيد الزمني على كيفية تنفيذ الرفع إلى قوة في لغة البرمجة. وباتخاذ Python مثالاً، توجد ثلاث طرق شائعة لحساب القوى.

  • لكل من المعامل ** والدالة pow() تعقيد زمني O(log⁡⁡a)O(\log⁡ a)O(log⁡a).
  • تستدعي الدالة math.pow() داخلياً الدالة pow() من مكتبة C، وهي تنفذ الرفع إلى قوة للأعداد العائمة، بتعقيد زمني O(1)O(1)O(1).

يستخدم المتغيران aaa وbbb مقداراً ثابتاً من المساحة الإضافية، لذا يكون التعقيد المكاني O(1)O(1)O(1).

إثبات الصحة

نستخدم البرهان بالتناقض، وننظر في الحالة n≥4n \geq 4n≥4 فقط.

  1. جميع العوامل ≤3\leq 3≤3: لنفترض أن مخطط القطع الأمثل يتضمن عاملاً x≥4x \geq 4x≥4. فيمكن تقطيعه أكثر إلى 2(x−2)2(x-2)2(x−2) للحصول على حاصل ضرب أكبر (أو مساوٍ). وهذا يناقض الافتراض.
  2. مخطط القطع لا يحتوي على 111: لنفترض أن مخطط القطع الأمثل يتضمن عاملاً قدره 111. فيمكن دمجه في عامل آخر للحصول على حاصل ضرب أكبر. وهذا يناقض الافتراض.
  3. مخطط القطع يحتوي على عاملي 222 على الأكثر: لنفترض أن مخطط القطع الأمثل يتضمن ثلاثة عوامل من 222. فيمكن استبدالها بعاملين من 333، للحصول على حاصل ضرب أكبر. وهذا يناقض الافتراض.
