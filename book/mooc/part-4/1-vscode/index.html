محرر Visual Studio Code ومفسر Python وأداة التنقيح المدمجة

  • تشغيل الشيفرة

أهداف التعلم

بعد هذا القسم

  • ستكون مجهزًا لاستخدام محرر Visual Studio Code في إتمام تمارين هذه الدورة
  • ستكون على معرفة بمفسر Python التفاعلي، وستكون قادرًا على استخدامه لتشغيل الشيفرة

حتى الآن كانت كل تمارين هذه الدورة تُنجَز مباشرة في صفحات الدورة داخل نوافذ محرر مدمجة. البرمجة في المتصفح مناسبة جدًا للخطوات الأولى في البرمجة، لكن حان الوقت الآن للبدء باستخدام محرر مستقل مخصص للبرمجة.

هناك العشرات من المحررات المختلفة الملائمة للبرمجة. في هذه الدورة سنستخدم محرر Visual Studio Code، الذي ذاع استخدامه في السنوات الأخيرة.

يُرجى تثبيت محرر Visual Studio Code على حاسوبك الآن. قد تحتاج أيضًا إلى تثبيت Python وإضافة Visual Studio Code الخاصة بـ Python. وستحتاج أيضًا إلى إضافة TMC، التي تتولى تشغيل الاختبارات المصاحبة للتمارين. في إضافة TMC، اختر MOOC بصفة المنظمة وPython Programming 2026 بصفة الدورة.

هناك دليل لتثبيت كل هذه الأشياء وتشغيلها. اقرأ التعليمات الخاصة بالعمل على التمارين وتسليمها، ثم أنجز المهمة أدناه:

تمرين برمجي: مرحبًا Visual Studio Code

اكتب برنامجًا يسأل المستخدم عن المحرر الذي يستخدمه. ينبغي أن يواصل البرنامج السؤال حتى يكتب المستخدم Visual Studio Code.

ألقِ نظرة على مثال السلوك المتوقع أدناه:

Editor: **Emacs**
not good
Editor: **Vim**
not good
Editor: **Word**
awful
Editor: **Atom**
not good
Editor: **Visual Studio Code**
an excellent choice!

إذا كتب المستخدِم Word أو Notepad، يردّ البرنامج بـ awful. أما خيارات المحررات غير المقبولة الأخرى فيتلقى الردّ not good.

يجب أن تكون ردود فعل البرنامج غير حساسة لحالة الأحرف. أي أن الإدخال نفسه من المستخدم بأحرف صغيرة أو بأحرف كبيرة أو بحالة مختلطة ينبغي أن يؤدي إلى الردّ نفسه:

Editor: **NOTEPAD**
awful
Editor: **viSUal STudiO cODe**
an excellent choice!

تلميح: أبسط طريقة لتحقيق ذلك هي تحويل كل الأحرف إلى الحالة نفسها. تابع lower في سلاسل Python يحوّل السلسلة النصية بالكامل إلى أحرف صغيرة. مثال على استخدامه:

mystring = "Visual Studio CODE"
if "visual studio code" == mystring.lower():
    print("this was the string I was looking for!")

ملاحظة: هذا التمرين لا يطلب منك كتابة أي دوال، لذا يجب أن لا تضع أي شيفرة داخل كتلة if __name__ == "__main__". الأمر نفسه ينطبق على أي تمارين قادمة لا تطلب الدوال صراحةً.

تشغيل الشيفرة

في Visual Studio Code، أسهل طريقة لتشغيل شيفرتك هي النقر على المثلث في الزاوية العلوية اليمنى. يحدث أحيانًا أن يبقى برنامج ما يعمل في الخلفية، ربما لأنه ينتظر إدخالًا من المستخدم أو أنه عالق في حلقة لا نهائية، دون أن تُدرك ذلك. قد لا تلاحظ ذلك إلا عندما تحاول تشغيل البرنامج التالي، الذي لن يعمل ببساطة لأن التنفيذ السابق ما زال يحتجز الموارد. الحل السريع هو الضغط في الوقت نفسه على المفتاحين Control+C، ما يوقف تنفيذ أي عملية جارية. يجب أن يعمل البرنامج التالي الآن جيدًا.

المفسر هو طريقة لتنفيذ شيفرة Python سطرًا بسطر بمجرد أن تكتبها. عندما تكتب سطرًا من الشيفرة وتضغط Enter، ينفّذ المفسر الشيفرة فورًا ويعرض عليك النتائج:

أي شيفرة Python يمكن كتابتها في ملف يمكن كتابتها أيضًا في المفسر. بل يمكنك حتى إسناد قيم إلى المتغيّرات وتعريف التوابع:

>>> t = [1,2,3,4,5]
>>> for number in t:
...   print(number)
...
1

3
4
5
>>> def absolute_value(number):
...   if number<0:
...      number = -number
...   return number
...
>>> x = 10
>>> y = -7
>>> absolute_value(number)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'number' is not defined
>>> absolute_value(x)
10
>>> absolute_value(y)
7
>>>

المفسر هو الأنسب لإجراء فحوصات صغيرة. فمثلًا، يمكنك تجربة الدوال والتوابع، أو التحقق مما إذا كانت موجودة أصلًا:

>>> "TextYteXt".toupper()
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
AttributeError: 'str' object has no attribute 'toupper'
>>> "TextYteXt".upper()
'TEXTYTEXT'
>>>

سلاسل Python النصية تحتوي على عدد كبير من التوابع المتاحة، كما ترى أعلاه. عند هذه النقطة قد يكون من الأفضل تجاهل أي توابع تحتوي على شرطة سفلية في أسمائها، لكن الباقي قد يكون مفيدًا فعلًا. بعضها يمكنك استنتاجه بتجربته، والبعض الآخر يمكنك البحث عنه على الإنترنت.

قوائم Python لا تحتوي على هذا العدد الكبير من التوابع:

لنجرّب بعضها، يبدو reverse وclear واعدين:

>>> numbers = [1,2,3,4,5]
>>> numbers.reverse()
>>> numbers
[5, 4, 3, 2, 1]
>>> numbers.clear()
>>> numbers
[]

كما ترى، هذه التوابع تؤدي تقريبًا ما تتوقعه من أسمائها.

لاحظ كيف أن المفسر لا يطبع أي شيء عند تنفيذ الأمر numbers.reverse(). والسبب هو أن المفسر لا يطبع شيئًا إلا إذا كان سطر الشيفرة يحتوي على قيمة. أما التابع reverse() هنا فلا يُرجع أي قيمة.

في المثال أعلاه طبَعنا قيمة القائمة numbers بكتابة اسم المتغيّر فقط. في الواقع، نادرًا ما يكون ضروريًا كتابة أوامر print صراحةً في المفسر. لكن يمكنك تضمينها إن أردت.

تذكّر أن تُغلق المفسر عند انتهائك. إن الأمران quit() وexit() يُغلقانه، وكذلك الضغط على المفتاحين Control+D (Linux/Mac) أو Control+Z (Windows). هذا مهم خاصةً في Visual Studio Code، إذ إن محاولة تنفيذ برنامج Python آخر بينما المفسر ما زال يعمل تؤدي إلى رسالة خطأ غامضة إلى حد ما:
