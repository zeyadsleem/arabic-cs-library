CLI

CLI (/docs/concepts/cli)

تعرّف على أوامر Better Auth CLI لتوليد مخططات قواعد البيانات وترحيلها والتحقق منها، وإنشاء المسؤولين الأوليين، وتهيئة المشاريع، وتوليد المفاتيح السرّية، وجمع معلومات التشخيص.

يأتي Better Auth مزوّدًا بأداة CLI مدمجة لمساعدتك على إدارة مخططات قواعد البيانات والتحقق منها، وإنشاء مستخدمين مسؤولين أوليين، وتهيئة مشروعك، وتوليد مفتاح سرّي لتطبيقك، وجمع معلومات تشخيصية حول إعدادك.

Generate

ينشئ الأمر generate المخطط المطلوب من قِبل Better Auth. إذا كنت تستخدم محوّل قاعدة بيانات مثل Prisma أو Drizzle، فسيولّد هذا الأمر المخطط المناسب لـ ORM لديك. وإذا كنت تستخدم محوّل Kysely المدمج، فسيولّد ملف SQL يمكنك تشغيله مباشرةً على قاعدة بياناتك.
