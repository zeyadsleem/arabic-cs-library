# المكتبة العربية لعلوم الحاسوب

الموقع المنشور: <https://zeyadsleem.github.io/arabic-cs-library/>

مشروع ترجمة عربية غير رسمي وغير تجاري لمصادر علوم الحاسوب المفتوحة، مبني
باستخدام **SvelteKit** مع دعم كامل للعربية واتجاه RTL.

## المتطلبات

- Node.js 20 أو أحدث
- pnpm

## الأوامر

```bash
pnpm install     # تثبيت الاعتماديات
pnpm dev         # تشغيل بيئة التطوير
pnpm build       # توليد المحتوى ثم بناء الموقع في build/
pnpm preview     # معاينة نسخة الإنتاج
pnpm deploy      # البناء ثم النشر على فرع gh-pages
```

## بنية المشروع

```
content/
  library.json                  بيانات كل الكتب (عناوين، أوصاف، تراخيص، حالة)
  hello-algo-structure.json     فهرس كتاب Hello Algo (فصول وأقسام)
  hello-algo/                   المحتوى العربي المترجم
content-src/hello-algo/         المحتوى الإنجليزي المحوّل
sources/hello-algo/             مصادر Hello Algo الأصلية (docs + codes)
scripts/
  import-hello-algo.mjs         استيراد الكتاب وتحويله (بما فيه شيفرة Go/TS)
  build-content.mjs             توليد الفهرس والبحث وصفحات المحتوى
src/                            تطبيق SvelteKit
static/images/hello-algo/       صور الكتاب
TRANSLATION.md                  دليل الترجمة والمصطلحات
```
