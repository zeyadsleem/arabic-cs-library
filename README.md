## جولة Go التفاعلية

الجولة كتاب داخل الفهرس: `/book/go-tour/`، والدرس الأول `/book/go-tour/welcome/index/`.

103 صفحات في 7 وحدات، بترجمة عربية كاملة لنص Go Tour الأصلي: جميع الفقرات
والعناوين والقوائم والتمارين والتلميحات والملاحظات والروابط، دون تلخيص.
النص الإنجليزي الكامل متاح داخل كل درس للمقارنة، وتظل الشيفرة الأصلية دون تغيير.
المحرر يدعم تلوين Go، الإكمال، أرقام الأسطر، تشغيل الشيفرة، تنسيق `gofmt`،
عرض الأخطاء والصور الناتجة، واستعادة المثال الأصلي.
تُحفظ التعديلات والتقدم محلياً في المتصفح، وتُشارك صفحات الدروس
بروابط مثل `/book/go-tour/basics/index/`. اختصارات الجولة الأصلية مدعومة:
`Shift+Enter` للتشغيل، و`Ctrl+Enter` أو `Cmd+Enter` للتنسيق، و`PageUp`/`PageDown`
للتنقل خارج المحرر. تلوين الشيفرة مفعّل دائماً ولا يوجد خيار لتعطيله.
تظهر الجولة ضمن بطاقات الكتب بنفس الغلاف والفهرس المعتادين. فهرس القارئ مغلق
افتراضياً ويمكن فتحه من الشريط العلوي. يأخذ الدرس المساحة الأكبر، والمحرر 34%
افتراضياً؛ يمكن سحب الفاصل في الاتجاه نفسه للحركة أو استخدام الأسهم لتغيير العرض.
على سطح المكتب يتمرر الدرس داخل لوحته بينما يظل المحرر ثابتاً. النص الإنجليزي
الكامل متاح داخل أكورديون أسفل الترجمة. حُذفت فقط تعليمة تبديل التلوين بطلب
المستخدم، وهو استثناء صريح في فحص الترجمة.

التشغيل الافتراضي والتنسيق داخل المتصفح باستخدام Yaegi v0.16.1 المجمّع إلى
WebAssembly، على غرار محرك `go-wasm` في LiveCodes. لكل عملية Web Worker منفصل
يمكن إنهاؤه للإلغاء أو عند انتهاء المهلة؛ لا تُرسل الشيفرة خارج المتصفح في هذا الوضع.
ملفات المحرك في `static/go-browser/`، وشفرة البناء في `tools/go-browser/`.
لتحديث المحرك: `go mod tidy` في ذلك الدليل ثم `pnpm build:go-browser` (يتطلب Go).
المحرر يعتمد التلوين دائماً؛ التنسيق يستعمل `go/format` داخل محرك Wasm.
حزم التمارين `pic` و`wc` و`reader` مكيّفة لالتقاط المخرجات، و`tree` من المصدر.
يتاح المترجم الرسمي اختيارياً للبرامج غير المتوافقة مع المفسّر؛ في التطوير والمعاينة
يمر عبر `/api/go/compile`، وعلى الاستضافة الثابتة يعتمد اتصال Playground المباشر.
التراخيص محفوظة بجانب المحرك. يستلهم التكامل LiveCodes ولا يضمّن تطبيقه كاملاً.

- `node scripts/import-go-tour.mjs`: تحديث لقطة المصدر الرسمي من `go.dev/tour/lesson`.
- `src/lib/tour/translations/`: الترجمة الكاملة، وحدة مستقلة في كل ملف JSON.
- `node scripts/prepare-go-tour-translations.mjs`: إعداد نسخ المصدر المقروءة دون الكتابة فوق ترجمة موجودة.
- `node scripts/build-go-tour.mjs`: التحقق من مطابقة كل عقدة HTML ورابط ومقطع شيفرة للمصدر قبل توليد بيانات الواجهة؛ يتوقف البناء عند حذف محتوى أو تغيير الشيفرة.
- `pnpm test:tour`: اختبارات الترجمة والبوابة والمتصفح، ومنها التشغيل المحلي مع حجب الخدمة الخارجية.
- الترخيص الأصلي محفوظ في `src/lib/tour/LICENSE` ويُنشر في `/go-tour-license.txt`.

## القراءة على الموبايل

صفحات الكتب والقارئ تستخدم تخطيطاً مشتركاً مناسباً للشاشات الصغيرة. فهرس
القارئ يُفتح من زر «فهرس الكتاب» بدلاً من احتلال مساحة قبل الدرس، ويمكن إغلاقه
بالزر أو مفتاح Escape. الجداول والمعادلات الطويلة وكتل الشيفرة تتمرر داخل
مساحتها دون توسيع الصفحة؛ الروابط والمقاطع القصيرة داخل السطر تلتف عند الحاجة.
على الموبايل تتبع شيفرة جولة Go نص الدرس، وتبقى الترجمة والنص الأصلي متاحين.

`pnpm test:mobile` يفحص صفحات جميع الكتب عند 320 و390 و768 بكسل، وقارئ كل
كتاب متاح داخل الموقع، مع عينات الجداول والشيفرة والرسوم والتنقل والسمة الداكنة.

## الأوامر

```bash
pnpm install     # تثبيت الاعتماديات
pnpm dev         # تشغيل بيئة التطوير
pnpm build       # توليد المحتوى ثم بناء الموقع في build/
pnpm preview     # معاينة نسخة الإنتاج
pnpm deploy      # البناء ثم النشر على فرع gh-pages
```

## بنية المشروع

```
content/
  library.json                  بيانات كل الكتب (عناوين، أوصاف، تراخيص، حالة، مرحلة، متطلبات)
  learning-path.json            المراحل وترتيب الكتب داخل كل مرحلة
  <book>-structure.json         فهرس كل كتاب مُترجم (فصول وأقسام)
  <book>/                       المحتوى العربي المترجم
content-src/<book>/             النص الإنجليزي الأصلي
scripts/
  import-hello-algo.mjs         استيراد Hello Algo وتحويله (مع شيفرة Go/TS)
  import-missing-semester.mjs   استيراد ترجمة Missing Semester العربية مع الفيديو
  build-content.mjs             توليد الفهرس والبحث وصفحات المحتوى لكل الكتب
src/                            تطبيق SvelteKit
static/images/                  صور الكتب
TRANSLATION.md                  دليل الترجمة والمصطلحات
docs/ROADMAP.md                 خطة التنفيذ الكاملة ومصادر كل كتاب وحالة كل مرحلة
```
