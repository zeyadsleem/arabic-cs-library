# ترجمة صفحات دورة MOOC (جامعة هلسنكي)

كل صفحة من صفحات الدورة تُترجم في ملف مستقل، ولا تُنشر الصفحة إلا إذا اجتازت كل
قواعد `scripts/lib/mooc-translation.mjs`. هذا الملف هو العقد بين المترجم والخط
الأوتوماتيكي: ما يجب ترجمته، وما يجب ألا يُمَس.

## موضع الملفات

- المصدر الإنجليزي: `content-src/mooc/<chapter>--<slug>.md`
- الترجمة العربية: `content-src/mooc-translations/<chapter>--<slug>.md`
  (نفس الاسم تمامًا، بلا استثناء).
- المخرج المنشور: `content/mooc/<chapter>--<slug>.md` — يبنيه `scripts/build-mooc.mjs`.

§89 صفحة: 14 جزءًا (`part-1` … `part-14`) و11 صفحة مساعدة (`auxiliary`). لكل جزء
صفحة فهرس اسمها `index`.

## شكل ملف الترجمة

```markdown
---
title: "المعلومات من المستخدم"
---

النص العربي الكامل للصفحة…
```

العنوان في `title` يجب أن يكون عربيًا. لا تكتب `book` أو `chapter` أو `slug` أو
`order` — الخط يقرأها من المصدر.

## ما لا يُمس أبدًا

1. **الشيفرة** داخل ```` ``` ````: انسخها كما هي حرفيًا — نفس المسافات البادئة،
   ونفس الكلمات، ونفس لغة التمييز (`python`، `json`، `sh`، `csv`…). لا تترجم
   التعليقات الإنجليزية داخل الشيفرة، ولا تعيد تسمية متغيّر أو دالة أو نوع.
   المسافات الزائدة في آخر السطر مُتجاهَلة، وما دون ذلك مطابق حرفيًا.
2. **أهداف الروابط**: كل `](هدف)` يبقى بنفس الهدف ونفس ترتيبه. يُترجم النص
   الظاهر فقط.
3. **الصور والمسارات**: `![بديل](/images/mooc/…)` — يُترجم النص البديل فقط،
   والمسار لا يتغيّر.
4. **وسوم HTML** وخصائصها (`div`، `class`، `href`، `src`، `sup`، `table`…).
5. **العلامات العربية الجاهزة** التي جاءت مسبقًا في المصدر (أداة الاستيراد نفسها
   تكتبها) — تُترك كما هي مع ترجمة اسم التمرين:
   - `> **تمرين تفاعلي: <اسم التمرين>**` — ترجم الاسم داخل العنوان فقط.
   - `> **تمرين برمجي: <اسم التمرين>**` — ترجم الاسم داخل العنوان فقط.
   - `> *ملاحظة: هذا التمرين يتطلب بيئة TMC التفاعلية…*` — كما هي.
   - `> **اختبار:** (مكون تفاعلي غير متاح في النسخة الثابتة - ID: …)` — كما هي.
   - `*سيتم عرض قائمة الصفحات في هذا القسم هنا.*` و`*سيتم عرض قائمة التمارين في هذا القسم هنا.*`
     و`*سيتم عرض قائمة جميع التمارين هنا.*` و`*جدول المحتويات*` — تُترك كما هي في ملفات المصدر
     والترجمة؛ إذ يستبدلها البناء (`scripts/build-mooc.mjs`) عند النشر بقوائم حقيقية للصفحات
     والتمارين وبجدول محتويات فعلي، فلا تُترجم ولا تُعدَّل يدويًا.
6. **الصناديق** التي حوّلتها الأداة إلى `> **عنوان الصندوق**` مع نص مُقتباس:
   اترجم العنوان والنص، وأبقِ شكل الاقتباس `>` سطرًا بسطر.

## ما يُترجم

كل نص ظاهر: العناوين بكل مستوياتها، الفقرات، القوائم، الجداول (بما فيها
الترويسات)، النص بين الرابطين، النص البديل للصور، وما داخل `*…*` و`**…**` و`` `…` ``.

## أسلوب الترجمة

- عربي فصيح بضمير المخاطب، بلا إيموجي ولا إضافات ولا حذف. لا تختصر أي فقرة.
- عند أول ذكر لمصطلح مهم ضع الأصل بين قوسين: «الدوال (functions)»، ثم استخدم
  العربية وحدها. لا تُكثر.
- أبقِ لاتينيًا: `Python`، `list`، `dict`، `class`، `object`، `None`، `lambda`،
  أسماء الدوال مثل `print` و`input`، وأي شيء يظهر في الشيفرة.
- المصطلحات المعتمدة في المكتبة: list = قائمة | dictionary = قاموس |
  tuple = صف | string = سلسلة نصية | loop = حلقة | iteration = تكرار |
  recursion = تعاود | function = دالة | parameter = معامل | argument = وسيط |
  class = صنف | object = كائن | attribute = خاصية | method = تابع |
  inheritance = وراثة | module = وحدة | file = ملف | exception = استثناء |
  raise = رفع | try/except = المحاولة/الالتقاط | generator = مولّد |
  comprehension = إدراك | sorting = ترتيب | index = فهرس | value = قيمة |
- الأرقام والحسابات تبقى كما هي. لا تغيّر أمثلة النتائج.
- لا تدمج سطرين في سطر واحد ولا تفصل سطرًا؛ حافظ على بنية الفقرات والقوائم.

## التحقق

بعد كل صفحة (أو كل دفعة) نفّذ:

```bash
node scripts/check-mooc.mjs <chapter>--<slug>
```

يجب أن يطبع `PASS` ويخرج بصفر. أي `FAIL` يعني أن الصفحة لم تكتمل، والرسالة
تقول بالضبط أي قاعدة انكسرت (عدد الشيفرات، تعديل شيفرة، اختلاف الروابط، نص
إنجليزي باقٍ، وسم غير مدعوم…).

للتحقق من الدورة كاملة:

```bash
node scripts/check-mooc.mjs
```

## صفحات طويلة

إن تجاوز النص حجم كتابة واحدة، اكتبه على مرحلتين: `write` للجزء الأول ثم ملف
مؤقت للجزء الثاني وادمجه بـ `cat` قبل التحقق. لا تُبقِ ملفات مؤقتة بعد
الانتهاء.
