# ترجمة صفحات دورات Steve Kinney

كل صفحة من صفحات الدورات الست عشرة تُترجم في ملف مستقل، ولا تُنشر الصفحة إلا إذا
اجتازت كل قواعد `scripts/lib/translation-rules.mjs`. هذا الملف هو العقد بين المترجم
والخط الأوتوماتيكي: ما يجب ترجمته، وما يجب ألا يُمَس.

## حالة النشر والترخيص

الدورات منشورة بموافقة كتابية من مؤلفها Steve Kinney، تحت رخصة
CC BY-NC-SA 4.0. الترجمة **غير رسمية وغير تجارية**، ولا تعني أي تأييد من المؤلف
أو من موقعه. تُنشر الصفحة عربيًا فقط بعد اجتيازها قواعد التحقق.

## موضع الملفات

- المصدر الإنجليزي: `content-src/kinney/<chapter>--<slug>.md`
- الترجمة العربية: `content-src/kinney-translations/<chapter>--<slug>.md`
  (نفس الاسم تمامًا، بلا استثناء).
- المخرج المنشور: `content/kinney/<chapter>--<slug>.md` — يبنيه `scripts/build-kinney.mjs`.

القيمة `chapter` هي مفتاح الدورة، و`slug` هو معرّف الصفحة داخل الدورة.

## شكل ملف الترجمة

```markdown
---
title: "الدوال كقيم (Functions as Values)"
---

النص العربي الكامل للصفحة…
```

العنوان في `title` يجب أن يكون عربيًا. لا تكتب `chapter` أو `slug` أو `order` أو
`source` — الخط يقرأها من المصدر.

## ما لا يُمس أبدًا

1. **الشيفرة** داخل ```` ``` ````: انسخها كما هي حرفيًا — نفس المسافات البادئة،
   ونفس الكلمات، ونفس لغة التمييز (`typescript`، `bash`، `tsx`، `json`، `css`…).
   لا تترجم التعليقات الإنجليزية داخل الشيفرة، ولا تعيد تسمية متغيّر أو دالة أو
   نوع. المسافات الزائدة في آخر السطر مُتجاهَلة، وما دون ذلك مطابق حرفيًا.
2. **أهداف الروابط**: كل `](هدف)` يبقى بنفس الهدف ونفس ترتيبه. الروابط في هذا
   الكتاب كلها مطلقة (`https://…`)، ويُترجم النص الظاهر فقط.
3. **الصور والمسارات**: يُترجم النص البديل فقط، والمسار لا يتغيّر.
4. **وسوم HTML** وخصائصها (`div`، `class`، `href`، `src`، `sup`، `table`…).
5. **مراسي العناوين** `{#english-slug}` التي يضيفها البناء: تُترك كما هي إن وُجدت.
6. **الرموز المُهرَّبة** `&lt;` و`&gt;`: تبقى مُهرَّبة. المصدر يكتب عناوين مثل
   `### Partial&lt;T&gt;` لأن ماركداون يقرأ `<` علامة وسم فيُخفي ما بعدها؛ لو
   أزلت التهريب لعُرض العنوان `Partial` فقط وضاع `<T>`.
7. **الصناديق** التي جاءت `> **Tip**` أو `> **Warning**` أو `> **Note**` مع نص
   مُقتبس: اترجم العنوان والنص، وأبقِ شكل الاقتباس `>` سطرًا بسطر. لا تُبقِ عنوان
   الصندوق إنجليزيًا.

## ما يُترجم

كل نص ظاهر: العناوين بكل مستوياتها، الفقرات، القوائم، الجداول (بما فيها
الترويسات)، النص بين الرابطين، النص البديل للصور، عناوين الصناديق، وما داخل
`*…*` و`**…**` و`` `…` ``.

## أسلوب الترجمة

- عربي فصيح بضمير المخاطب، بلا إيموجي ولا إضافات ولا حذف. لا تختصر أي فقرة.
- عند أول ذكر لمصطلح مهم ضع الأصل بين قوسين: «المكوّنات (components)»، ثم استخدم
  العربية وحدها. لا تُكثر.
- أبقِ لاتينيًا: أسماء الأطر والمكتبات (`React`, `TypeScript`, `Vite`, `Vitest`,
  `Tailwind`, `Storybook`, `Figma`, `AWS`, `Docker`)، وأعلام سطر الأوامر
  (`--watch`, `-p`)، ومسارات الملفات، وأسماء الدوال والمتغيّرات، وأي شيء يظهر
  في الشيفرة.
- المصطلحات المعتمدة في المكتبة: component = مكوّن | hook = خُطّاف | state = حالة |
  props = خصائص | render = تصيير | test = اختبار | test suite = مجموعة اختبارات |
  mock = بديل مُحاكى | stub = بديل | assertion = تحقّق | build = بناء |
  bundle = حزمة | dependency = اعتماد | deploy = نشر | environment variable =
  متغيّر بيئة | repository = مستودع | branch = فرع | commit = إيداع |
  request = طلب | response = استجابة | endpoint = نقطة نهاية | middleware = وسيط |
  cache = ذاكرة مؤقتة | type = نوع | interface = واجهة | generic = عام |
  union type = نوع اتحادي | function = دالة | class = صنف | object = كائن |
  module = وحدة | file = ملف | attribute = خاصية | method = تابع | index = فهرس |
  value = قيمة | iteration = تكرار.
- الأرقام والحسابات تبقى كما هي. لا تغيّر أمثلة النتائج أو مخرجات الطرفية.
- لا تدمج سطرين في سطر واحد ولا تفصل سطرًا؛ حافظ على بنية الفقرات والقوائم.

## التحقق

بعد كل صفحة نفّذ:

```bash
node scripts/check-kinney.mjs <chapter>--<slug>
```

يجب أن يطبع `PASS` ويخرج بصفر. أي `FAIL` يعني أن الصفحة لم تكتمل، والرسالة تقول
بالضبط أي قاعدة انكسرت (عدد الشيفرات، تعديل شيفرة، اختلاف الروابط، نص إنجليزي
باقٍ، وسم غير مدعوم…). و`PENDING` تعني أن ملف الترجمة مفقود.

لعدّ التقدّم في الكتاب كاملًا:

```bash
node scripts/check-kinney.mjs
```

يطبع سطرًا واحدًا بالمجموع: كم صفحة اجتازت، وكم ما زالت ناقصة، وكم فشلت. أعضاء
المصفوفة المرقون بلا قيم يُعرضون في وضع «معلّق» ولا يوقف ذلك البناء ما دام الكتاب
بحالة `planned`.
